# 桌面框架与包结构

## 包结构和依赖方向

桌面基础能力由当前仓库中的两个包提供：

| 分发包 | Python 导入名 | 位置与职责 |
| --- | --- | --- |
| `mindmap-docking` | `mindmap_docking` | `packages/mindmap-docking/`，停靠、标签、分屏、主题与布局持久化 |
| `mindmap-shell` | `mindmap_shell` | `packages/mindmap-shell/`，主窗口、应用动作、菜单、启动与项目模板 |
| `mindmap-workbench` | `mindmap_workbench` | `apps/mindmap-workbench/`，思维导图桌面应用 |

应用外壳依赖停靠组件，应用通过 `shell_adapter.py` 组合外壳与导图画布。
停靠组件不导入桌面外壳或业务代码，桌面外壳不导入导图画布或引擎；`mindmap-qt` 仍可独立嵌入其他 Qt 软件。
四个引擎包继续保持纯 Python，不引入 Qt 或桌面依赖。

全部八个成员共用根目录的 `uv.lock` 和 `.venv`。开发依赖通过 `workspace = true` 解析到本仓库源码，
构建后通过 wheel 的正常包依赖安装。克隆、同步、测试、构建和安装均不要求存在其他源码仓库。

## 文档与动作所有权

`DocumentSpec.factory` 注册时创建文档控件，`can_close` 可拒绝关闭。
`dispose_on_close` 默认关闭，普通宿主关闭后缓存实例和业务历史；启用后调用关闭通知并移除注册、延迟销毁页面。
`close_documents(ids)` 先检查全部目标，全部通过后再移除页面；任一失败不关闭目标标签。
`active_document_id` 和 `document_activated` 表示逻辑活动文档；`activate_document(id)` 激活已有标签与焦点，不移动所在分屏。
文档焦点可更新活动会话，工具面板焦点不覆盖它；没有打开文档时标识为空字符串。
工具窗口通过 `ToolWindowSpec` 延迟创建，同一实例可以在主窗口的左右停靠区、底部、临时展开容器和编辑器分屏间迁移。

`manager.set_document_actions(document_id, actions)` 将已有动作放到当前文档标签栏右侧。
动作继续由业务持有并管理生命周期，框架仅创建展示按钮，自动同步图标、提示和启用状态。
传入空序列清除入口；未知文档抛出 `KeyError`，非法动作抛出 `TypeError` 并保留原配置。
关闭后重开、标签切换、分屏和布局恢复仍使用同一动作，不另行配置快捷键。

工作台的撤销、重做采用该入口，适应窗口、回到中心采用画布右下角浮条；两处都复用画布动作。
浮条属于视图控件，不属于图形场景，不参与 PNG、SVG、PDF 导出。
每个编辑分屏由停靠组件统一绘制外层圆角，标签栏与画布之间只有一条贯穿宽度的细分隔线。
工作台以 `MindMapWidget(embedded=True)` 嵌入画布，移除内部圆角和内边距；
显示底色使用外壳的 `editor-bg`，导出仍使用导图文档主题，切换明暗外壳不产生文档修改。

## 单主窗口和菜单

工作台主菜单依次为文件、编辑、视图、设置，退出仅保留文件菜单入口。
视图菜单从放大开始，不再提供“显示导图”及工作台的 `show_document()` 方法。
导图标签仍可关闭；工作台按文件创建独立会话，不再缓存关闭的画布和面板。
启动和关闭全部导图后显示空白页；新建先选保存位置并写入，打开不同文件新增标签，失败或取消不创建会话。
编辑区可通过 `set_empty_widget_factory(factory)` 给每个空分组提供页面，页面不注册文档、不进入标签和快照。
工作台的 `MindMapSessionManager` 管理文件归属和500毫秒防抖自动保存，`MindMapSession` 独立持有引擎及全部编辑组件。
菜单和文件动作跟随活动会话；外层只注册一套大纲、属性容器，以堆叠页面切换各会话内容。
固定 `DOCUMENT_ID` 已删除，窗口 `canvas`、`engine`、`files`、`panels` 是只读活动访问属性，空会话返回 `None`。
窗口新增 `sessions`、`active_session`、`save_all()`；`new_document(path=None)` 可直接指定目标路径。
“保存全部”使用 Ctrl+Alt+S，按标签顺序提交并保存，失败停止且定位错误会话，成功保持原活动标签。
单标签关闭保存所属文件；关闭其他标签和退出先保存全部目标，任一失败全部保留。
自动保存调用文件控制器的 `save_committed()`，只写正式快照，不提交输入、不取消弹层、不清空历史。
文件打开只支持 `.mindmap` 原生导图，JSON、Markdown、文本和扩展格式的文件导入流程及待导入状态已删除。
`MindMapFileController.open_path(path)`、会话管理器与工作台同名接口不再接受 `format_id` 参数。
打开对话框使用固定原生格式筛选，不显示“所有文件”；命令行和手工路径同样校验扩展名及原生容器内容。
新建、保存、保存全部、另存为和自动保存均固定使用原生编码；保存对话框只显示 `思维导图 (*.mindmap)`，不枚举额外完整格式。
省略扩展名时补齐 `.mindmap`，原生后缀忽略大小写，其他后缀在写入前拒绝；错误或取消不更新路径及保存标记，首次写入失败不创建标签。
原生编解码器必须可完整读写，不可用时明确失败，不回退 JSON。新建和另存为不能覆盖其他会话正在使用的文件，路径占用检查在补齐后缀之后执行。
额外编解码器继续用于底层通用文件接口和剪贴板，不能通过注册扩展扩大应用的文件打开或保存范围；不迁移配置或转换用户文件。
文档导出菜单和文件控制器的 `export_document_dialog()`、`export_path()` 已删除，不保留兼容入口；
“文件 → 导出图形”子菜单依次提供 PNG 图片、SVG 矢量图、PDF 文档，选择后直接进入对应格式的保存对话框，保留折叠范围选择。
打开、保存、另存为和剪贴板所需的格式注册表、编解码器及原子写入保持可用。
工作区菜单、工具搜索、视图中的重复滚轮入口及算法选择菜单已删除；滚轮行为统一在导图设置中调整。
树形布局引擎、布局方向、导图紧凑布局及底层算法扩展接口保持可用。

停靠组件和外壳统一采用单主窗口，不再支持辅助工作区、浮动／独立面板、面板最大化和全部隐藏／恢复。
面板右键菜单及双击不再触发这些操作；主窗口内拖动、单面板隐藏、标签和分屏继续支持，拖出窗口释放取消移动。
主窗口自己的最小化、最大化和关闭继续保留。大纲、节点属性使用 Alt+1、Alt+2，Alt+3 打开导图设置。
工作区导航快捷键 Escape、Shift+Escape、F12、F6，全部隐藏快捷键 Ctrl+Shift+F12 和面板最大化快捷键均已移除；
Escape 继续用于画布取消编辑或退出分支聚焦，隐藏活动面板后内部交还文档焦点。
删除的公共接口及显示模式见[停靠组件说明](../packages/mindmap-docking/README.md)。

## 配置与数据

桌面应用 ID 为 `mindmap-workbench`。导图文件采用版本 2，桌面布局快照采用版本 1，
窗口布局和滚轮偏好独立于导图文件保存。
工作台启用 `DockManager(preserve_open_documents=True)`：恢复有效布局和默认布局保留全部已打开导图及活动会话。
普通宿主默认关闭该选项，仍按快照恢复文档可见状态。旧会话中的文档标识不用于重开文件，未知标识会被过滤。
布局快照不保存导图路径或内容；本版不支持导图重启恢复、最近文件或草稿恢复。
外壳主题和布局共享，滚轮、粘贴偏好共享；大纲层级与展开状态按会话保留，最近层级作为后续会话默认值。

未显式指定 `storage_dir` 或 `--state-dir` 时，读取 Qt 用户配置位置下的
`mindmap/<application_id>/`，其中 `layouts-v1.json` 保存布局，`preferences.ini` 保存导图滚轮偏好。
指定独立配置目录时，全部配置写入该目录，不访问默认配置位置。

设置菜单保持平铺：外观组提供浅色、深色和紧凑模式；界面显示组提供停靠栏及标题按钮开关；
布局组提供宽屏布局及左右并排选项。三组仅使用分隔线区分，由左上角主菜单中的设置子菜单承载，
子菜单顶部提供“导图设置”。右上角不再显示齿轮，Alt+3 可在主菜单按钮下直接展开导图设置。

窗口排布只保留自动会话保存与恢复，以及通过 `Shift+F12` 恢复宿主建立的默认布局。
命名布局菜单及管理接口已删除，`restore_layout(snapshot)` 仅接受快照字典，
恢复默认模板使用 `restore_default_layout()`。会话文件仍采用版本 1，只写入 `schema_version` 和 `session`；
加载旧文件时忽略 `current_layout`、`layouts`，下一次正常保存时清除这两个字段。
旧多宿主会话先完整校验，再合并到 `main`：主分屏与当前标签保留，辅助宿主标签按文件顺序追加到主窗口当前组并去重。
旧文件缺少当前组信息时优先活动工具标签组，否则回退第一个标签组；新快照记录可选的 `current_group` 字段。
浮动／独立面板转成固定停靠，保留可见性并优先返回最后停靠位置；同格冲突优先同边空位，再使用其他空位，六区全满时追加为编辑器标签，保留打开状态。
辅助窗口位置不再应用，未注册工具同样完成迁移。正常保存只保留主宿主，并清除面板浮窗几何。
无效快照在修改界面前拒绝；自动加载损坏会话仍提示错误并回退内建默认快照，原子保存机制不变。

运行时导入、分发包名、命令入口、资源署名与界面均采用本项目命名。
桌面应用通过 `mindmap_workbench.shell_adapter` 接入外壳。

## 测试与发行

桌面框架核心回归测试位于 `tests/desktop/`，由根目录 pytest 配置统一收集。
测试覆盖停靠、迁移、布局恢复、动作、焦点、主题、模板、资源和包边界。

```powershell
uv sync --locked --all-packages --group dev
uv run --locked --all-packages pytest
uv run --locked --all-packages ruff check .
uv build --all-packages
uv run --locked --all-packages python scripts/verify_wheels.py
uv run --locked --all-packages python scripts/verify_workbench.py
```

wheel 验收脚本仅从当前仓库 `dist/` 读取八个成员，在仓库外分别验证独立安装、依赖隔离和桌面完整流程。
它不接受外部框架 wheel 路径。报告写入 `.artifacts/wheel-verification.json`，固定发行版本写入
`.artifacts/release-constraints.txt`。视觉验收覆盖明暗主题和 100%、150%、200% 三档缩放。
