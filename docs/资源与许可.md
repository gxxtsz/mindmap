# 桌面基础包的资源与许可

`mindmap-docking`、`mindmap-shell` 及随包项目模板采用 MIT 协议，版权署名为
`Copyright (c) 2026 mindmap contributors`。各包与模板内的 `LICENSE` 保留完整许可正文。
许可证采用标准英文原文，本文件提供中文说明。

## 默认资源

停靠组件的 `src/mindmap_docking/resources/` 包含两套主题 JSON 和 21 个 SVG 图标，随 wheel 一起交付。
主题与图标统一采用本项目署名。SVG 文件包含 MIT SPDX 注释，主题 JSON 记录许可和作者。

`manifest.json` 记录全部 23 个资源文件及其 SHA-256，桌面测试核验资源清单和内容摘要。
主题 JSON、资源清单和全部 SVG 统一以 UTF-8、LF 换行保存，根目录 `.gitattributes` 对当前桌面包路径固定此规则，
保证 Git 自动换行配置开启或关闭时，检出文件与 wheel 中的资源字节保持一致。
新增或修改资源时，先统一文件换行符，再按实际文件字节计算 SHA-256，并同步更新清单、作者和许可说明。
校验源码或 wheel 时直接计算原始字节摘要，不转换换行符；修改 Git 规则后，已有检出目录中的资源也需要统一为 LF。

Qt、PySide6 及其他运行依赖继续适用各自许可证。

基础包许可证：[停靠组件](../packages/desktop/mindmap-docking/LICENSE)、[桌面外壳](../packages/desktop/mindmap-shell/LICENSE)。
