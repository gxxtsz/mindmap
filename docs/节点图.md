# 节点图

选中导图里的文字节点，在编辑菜单或节点右键菜单选择「添加图」。图页和导图树页共用画布，每个标签分别记录自己的缩放、平移和选择。已有图时，可以点击文字节点上的图标打开。图页路径栏可返回所属节点，最近访问可重新进入该图。

## 编辑节点和连线

- Tab 添加节点，已有单个选中节点时从该节点连向新节点。Enter 添加独立节点。双击或按 F2 编辑标题。
- 鼠标左键拖动节点或已选中的一组节点，松手后保存位置。右键拖动平移画布。滚轮行为和缩放按钮与树页共用。
- 悬停或单选节点时，节点右侧会出现带加号的出线把手。把它拖到目标节点后松手，虚线箭头会变成正式连线。拖回同一个节点可以创建自环。也可以在右键或编辑菜单里选择「添加连线…」，指定起点和终点。
- 点击一条可见连线即可选中。拖动空心把手改接起点，拖动实心把手改接终点。有效的落点会高亮。按 Esc 或在空白处松手可取消拖动，重复连线和原端点也会取消。改接成功后，自动布局节点会按新关系重排，手动移动过的节点仍使用保存坐标。
- 选中连线后可按 Delete 删除，也可右键选择「删除连线」。选中节点时，Delete 删除所选节点及其相连的线。每次完成的连线编辑都可单独撤销或重做，并同步到同一张图的其他标签。
- 复制所选节点时，一同复制两端均在选择内的连线。粘贴使用新的局部标识，并将连线接到相应的新节点。
- 在右侧打开「连线筛选」，勾选要隐藏连线的节点。单项勾选和批量操作会随导图保存。「临时显示全部」只影响当前标签的视图，临时显示的连线也可以编辑。离开图页后恢复持久筛选。

## 图文本

选择「编辑图文本…」可编辑当前图的完整定义。应用后可通过一次撤销恢复之前的内容。

```text
# 定义应用、核心及一个独立节点
节点 app "应用"
节点 core "核心"
节点 note_1 "稍后处理"
app -> core
```

- `节点 标识 "标题"` 声明节点。标识区分大小写，以英文字母或下划线开头，后续可以使用英文字母、数字、下划线和连字符。标题按 JSON 字符串语法书写，例如 `"第一行\n第二行"`。
- `起点 -> 终点` 声明有向连线。两端都要在同一份文本中声明，声明可以位于连线之后。可以使用自环、双向连线和环形关系。同一个有序端点对只出现一次。
- 空白行和以 `#` 开头的整行注释会被忽略。重新打开文本时会按已保存的节点和连线生成规范文本。
- 已保留的节点标识沿用手动位置与筛选。删除节点声明时也要移除引用它的连线。输入有误时，按提示行号修改后可再次应用。
