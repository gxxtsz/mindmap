# 节点图

选中导图里的文字节点，在编辑菜单或节点右键菜单选择「添加图」。图页和导图树页共用画布，每个标签分别记录自己的缩放、平移和选择。已有图时，可以点击文字节点上的图标打开，也可以从最近访问重新进入。

图页路径沿用思维导图的页面层级，省略普通分支，以「所属节点名 · 图」结尾。点击祖先页面可定位页根，左侧箭头返回并选中图的所属节点。点击当前图页项可将整图居中，保留缩放比例和选择。窗口较窄时可通过「…」跳转，右键点击路径栏可复制完整页面路径。

## 编辑节点和连线

- Tab 添加节点，已有单个选中节点时从该节点连向新节点。Enter 添加独立节点。双击或按 F2 编辑标题。
- 鼠标左键拖动节点或已选中的一组节点，松手后保存位置。右键拖动平移画布。滚轮行为和缩放按钮与树页共用。
- 悬停或单选节点时，节点右侧会出现带加号的出线把手。把它拖到目标节点后松手，虚线箭头会变成正式连线。拖回同一个节点可以创建自环。也可以在右键或编辑菜单里选择「添加连线…」，指定起点和终点。
- 普通连线显示为灰蓝色细线。选中节点时，与之相连的入边、出边和自环以主题色高亮。直接选中的连线和箭头显示为琥珀色，线身加粗，并在交叉处与普通线留出细小间隔。
- 点击线身或箭头可单选，按住 Ctrl 点击可逐条增减。按住 Shift 从空白处拖框可替换选线，Ctrl+Shift 拖框可追加。选线框碰到线身或箭头时会选中对应连线。普通拖框用于选择节点。状态栏分别显示已选节点数和连线数。
- 单选一条连线后，拖动空心把手改接起点，拖动实心把手改接终点。有效的落点会高亮。按 Esc 或在空白处松手可取消拖动，重复连线和原端点也会取消。改接成功后，自动布局节点会按新关系重排，手动移动过的节点仍使用保存坐标。
- 选中一条或多条连线后，按 Delete 或使用编辑菜单的「删除」即可一次删除。右键点击已选连线可删除整组。选中节点时，Delete 删除所选节点及其相连的线。一次撤销可恢复一次批量删除，内容修改会同步到同一张图的其他标签。
- 复制所选节点时，一同复制两端均在选择内的连线。粘贴使用新的局部标识，并将连线接到相应的新节点。

## 图页面设置

打开右侧停靠栏的「图页面设置」，点击「DOT 自动布局」。编辑菜单和图页右键菜单也提供同名操作。整张图会用内置算法按有向连线重新分层，当前标签随即适应窗口。

操作会清除全图的手动坐标，自动布局状态随导图保存并同步到其他标签。撤销一次即可恢复全部原位置。后续增删节点或修改连线时，图会继续自动重排。再次手动拖动节点即可固定它的位置。

以前保存过连线筛选的导图会显示全部连线，正常保存时清空旧筛选记录。

## 图文本

选择「编辑图文本…」可编辑当前图的完整定义。应用后可通过一次撤销恢复之前的内容。

```text
# 定义应用、核心及一个独立节点
节点 app "应用"
节点 core "核心"
节点 note_1 "稍后处理"
app -> core
```

- `节点 标识 "标题"` 声明节点。标识区分大小写，以英文字母或下划线开头，后续可以使用英文字母、数字、下划线和连字符。标题按 JSON 字符串语法书写，例如 `"第一行\n第二行"`。
- `起点 -> 终点` 声明有向连线。两端都要在同一份文本中声明，声明可以位于连线之后。可以使用自环、双向连线和环形关系。同一个有序端点对只出现一次。
- 空白行和以 `#` 开头的整行注释会被忽略。重新打开文本时会按已保存的节点和连线生成规范文本。
- 已保留的节点标识沿用手动位置。删除节点声明时也要移除引用它的连线。输入有误时，按提示行号修改后可再次应用。
