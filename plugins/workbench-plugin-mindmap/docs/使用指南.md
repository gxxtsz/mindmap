# 思维导图插件

本插件通过公开接口向个人工作台注册导图编辑器、面板、菜单与自动保存。当前架构、状态存储及扩展说明见[工作台运行时](../../../packages/workbench-runtime/README.md)。本文保留完整的导图操作说明。

本目录统一管理导图业务：[adapter](../adapter/README.md) 保存工作台适配包，`engine/` 保存核心、布局和格式三个独立包，`qt/` 保存渲染、表单、画布和面板四个独立包。每个包的测试随源码放置；通用宿主与桌面基础设施位于仓库的 `packages/`。

这些组件保留现有分发名和 `mindmap_core`、`mindmap_layouts`、`mindmap_formats`、`mindmap_qt_*` 导入路径。根工作区显式注册所有成员；本分组目录不设置 `pyproject.toml`，确保从每个包目录也能发现根工作区。适配包的源码发行包与 wheel 只包含自身内容，通过依赖声明安装其他组件。

- **运行环境：** 支持 Python 3.12、3.13，当前工作区锁定 PySide6 6.12.0。

## 快速开始

克隆本仓库后直接在根目录运行，开发与发行均不需要其他源码目录：

```powershell
uv sync --locked --all-packages --group dev
uv run --locked --package personal-workbench personal-workbench
```

命令末尾可追加待打开的 `.mindmap` 原生导图路径。其他启动参数如下：

| 参数 | 行为 |
| --- | --- |
| `--theme light\|dark` | 设置外壳主题，优先于已保存的外壳主题 |
| `--state-dir 目录` | 使用独立的本机配置目录 |
| `--no-restore` | 跳过桌面布局和导图恢复；最近文件、滚轮和大纲层级等本机偏好仍读取 |
| `--compact` | 启用外壳紧凑模式；导图紧凑布局由“导图设置”管理 |
| `--size 宽x高` | 指定逻辑像素尺寸，默认 1440x900，范围为 860x540 至 8000x8000 |
| `--screenshot 文件.png` | 保存窗口截图及同名 JSON 元数据后退出；导图图形导出使用应用中的导出操作 |

## 多导图与分屏

### 工作区与新建

- **主窗口：** 始终只有一个主窗口，支持多个独立导图标签和主窗口内分屏。

- **空白页：** 首次启动不自动创建导图，空编辑分组显示“新建导图／打开文件”，关闭全部导图后回到空白页。

- **面板显隐：** 没有打开导图时，大纲、节点属性和导图设置面板及其操作入口暂不显示；打开或新建导图后按原布局恢复，保留面板的显隐、停靠位置和宽度偏好。

- **新建：** 新建先选择文件名和保存位置，首次写入成功后才创建标签；取消或失败不影响已打开会话。

- **打开：** 打开不同文件始终新增标签，已有空白分组不会生成伪文档标签；相同规范化绝对路径优先保留当前同文件标签，否则激活视觉顺序中的首个。

- **路径比较：** Windows 路径忽略大小写；重复打开不重新加载内容、不改变标签顺序或分屏位置。

### 复制标签与共享文档

- **复制入口：** 文件标签右键提供“复制标签”，针对命中的标签在原标签右侧创建并激活独立视图，非活动标签也可直接复制。

- **视图继承：** 新标签继承来源当前页、缩放、位置、选择及只读状态；可继续用“向右拆分／向下拆分”并排显示。

- **输入法与内存文档：** 复制直接使用共享内存文档，不创建文件副本、不重新读盘、不调整最近记录；来源或活动标签仍有输入法候选时不创建标签。

- **共享与独立状态：** 同文件标签共享编辑、撤销重做、修改标记、保存错误、文件大小及一套自动保存；各自保留导航、选择、视口和只读开关。

- **外部视图更新：** 普通修改只调整发起标签的选中与定位，其他标签保留有效视图；当前页被删除时回退有效祖先，失效选择按原规则过滤。

- **另存为：** 任一标签另存为成功后，全部关联标签统一更新名称和路径；失败或取消保留原文件归属。

- **路径占用：** 新建和另存为禁止覆盖另一打开会话占用的文件。

- **文档与会话职责：** 文件级文档对象统一持有引擎、路径、历史、修改状态和保存调度；标签级会话分别拥有画布、文件控制器、大纲、属性、选择、视口、临时导航与只读状态。

- **标签状态：** 标签显示文件名和修改星号，悬停显示完整路径；保存失败的标签附加“保存失败”，提示中保留所属文件错误。

### 活动会话与面板

- 外壳只注册一套大纲和属性容器，通过堆叠页面切换各会话的面板；切换前提交原会话的有效输入并关闭旧弹层。

- 点击标签或聚焦另一分屏画布可切换活动会话。菜单、侧栏、标题、状态栏、保存和导出均作用于当前活动会话。

## 最近文件与启动恢复

### 最近文件入口

- 主菜单按钮右侧仅显示“当前导图名称＋下拉箭头”，无活动导图时显示“最近文件”；名称前不放图标，长名称居中省略，悬停显示完整路径。

- 入口平时背景透明，悬停、按下或菜单展开时使用灰色背景；鼠标移入菜单后入口保持灰底，收起后按实际悬停状态恢复，深色主题使用对应灰色。

- 下拉列表保留最近20个导图，显示文件名及所在目录并勾选当前文件，支持鼠标、方向键和回车选择。

- 成功新建、打开、重复打开或另存为后置顶；普通标签切换、自动保存及启动恢复不调整排序。

- 下拉菜单提供“打开文件…”和“清空最近记录”；清空记录不影响当前标签及退出时的恢复集合。

### 恢复集合与视图

- 默认启动时重开上次正常退出时仍打开的全部导图，恢复标签顺序、分屏位置和活动导图，以及每份文件最后所在的主导图、子导图或详情页。

- 每个标签分别恢复退出时当前页的缩放、场景中心、节点选择和导航临时显示范围，其他已访问页的视图缓存不落盘；主动关闭的标签不重开。

- 版本1退出记录允许同路径对应不同标签标识，恢复时每份文件只加载一次再创建共享视图；不可用的重复路径只汇总提示一次，旧记录继续兼容。

### 失效文件与页面

- 缺失、损坏或不可读的文件逐份跳过并汇总提示；原活动文件失败时选中首个成功恢复的文件，全部失败则显示空白页。

- 失败文件仍保留在最近列表中，可以修复文件或恢复存储设备后重试。

- 手动关闭标签后重新打开文件仍从主导图开始，以100%显示并居中根节点。

- 恢复时页面已不存在则回到主导图；失效或属于其他页的选择会过滤，原本为空的选择保持为空，非空选择全部失效时选中页根。

- 无效视图字段只使对应页回退默认视图，不影响其他文件恢复；页面按标识匹配，同名、改名或调整归属后仍定位原页面。

- **启动选项：** 命令行指定文件在恢复完成后打开并激活；若该文件已经恢复，只切换原标签。`restore=False` 与 `--no-restore` 跳过布局和导图恢复，仍读取最近文件。

## 最近访问页面

- “最近访问”侧栏首次在左上展开，与大纲、收藏和灵感共用左侧区域；侧边按钮、视图菜单或 `Alt+7` 切换，布局随本机保存。旧布局首次补齐时会显示该面板，已有记录的显隐和位置继续恢复。
- 每份文件保留最近 50 个不同页面；同文件复制标签共享记录，各标签保留独立当前页高亮。主导图、子导图、详情页和每个独立想法都可记录，欢迎页及灵感空态不记录。
- 单击或方向键选择后按 Enter 在当前标签跳转；标题、类型及完整路径用于区分同名页面。跳转复用输入法检查、有效输入提交和页面视口缓存，从列表打开想法时不会自动切走本侧栏。
- 文件级 `RecentPageHistory` 管理稳定的“页面 ID＋想法根 ID”键并同步各面板；只有已安装的活动标签产生访问。启动批量恢复期间屏蔽临时页面，结束后只记录最终活动页。
- 页面摘要按当前文档刷新，改名和移动不改变顺序；删除、转换或归并导致的失效条目被移除，撤销恢复实体不会自行重新插入尚未再次访问的页面。
- `DocumentState` 的可选 `recent_pages` 字段按规范化绝对路径保存记录，兼容缺少此字段的版本 1 配置。坏条目单独丢弃，500 毫秒防抖原子写入，关闭标签和退出时刷新；保存失败保留内存记录并显示中文提示。
- 另存为成功后复制历史到新路径并保留原路径，新建覆盖同路径时重置历史。访问历史不改导图文件、撤销历史或修改标记，也不改变最近文件的排序及上次正常退出快照。

## 文件操作与导出

### 菜单与原生文件

- 主菜单依次为文件、编辑、视图、设置。文件菜单依次提供新建、打开、打开所在文件夹、保存、保存全部、另存为、导出图形、导出当前页为 TXT、退出。

- **拖放打开：** 从资源管理器把 `.mindmap` 文件拖到工作台窗口，松手后打开。可一次拖入多个文件，工作台按顺序打开导图，跳过目录和其他类型。重复拖入已打开的导图会激活原标签。单份读取失败时可在状态栏和操作日志查看提示，其余文件继续打开。在大文件加载窗口点击「取消」会停止本批次，已打开的标签保留。

- **打开所在文件夹：** 文件菜单操作当前活动导图，标签右键菜单在“复制标签”后提供同名入口，操作被点击的标签并保留当前活动标签。使用系统默认文件管理器打开父目录，不选中文件，无默认快捷键；无活动文件时禁用文件菜单入口，只读导图仍可使用。

- **目录与文件状态：** 每次使用目标标签的最新路径，另存为及同文件多标签自动跟随；文件已被外部删除但父目录存在时仍可打开。该操作不主动提交编辑或保存，也不调整最近文件记录；目录失效或系统拒绝打开时显示中文状态提示，结果按目标导图记录日志，不改变保存错误状态。

- **接入接口：** `window.open_file_directory(session_id=None) -> bool` 默认使用活动会话，传入标签标识时使用指定会话；返回系统是否接受打开请求，窗口已释放、标签失效或没有路径时返回 False。

- 保存全部使用 Ctrl+Alt+S；无导图时禁用编辑、保存、导出和导图设置，外壳主题、布局、新建和打开继续可用。

- 文件打开只支持 `.mindmap`，打开对话框只显示原生格式，不再提供“所有文件”和扩展格式筛选。

- JSON、Markdown、文本及额外注册格式的文件打开／导入流程已删除；手工输入路径和命令行也执行相同限制。

- 扩展名忽略大小写，改名后的其他格式仍必须通过原生容器校验，失败不创建会话、不提交已有输入。

- 新建、保存、保存全部、另存为和自动保存只写入 `.mindmap`；保存对话框固定显示 `思维导图 (*.mindmap)`。

- 省略扩展名时补齐 `.mindmap`，大小写不同的原生扩展名保持原样；输入其他扩展名提示“仅支持保存为 .mindmap 文件”，不静默改名、不写文件。

- 路径限制统一在写入前执行，手工路径及额外完整格式注册均不能绕过；未注册可用的原生编解码器时明确失败，不回退 JSON。

- 取消或失败保留原绑定路径、内存内容和修改状态，首次保存失败不创建标签；图形导出不受原生保存限制影响。

- 底层通用文件与内存编解码接口保留，复制粘贴继续复用 JSON、Markdown 和文本编解码器；不转换或删除已有文件。

### 图形导出

- 文件菜单中的“导出图形”子菜单依次列出 PNG 图片、SVG 矢量图、PDF 文档。

- 选择后直接打开所选格式的保存对话框，默认文件名与文件筛选均对应当前格式，随后选择是否展开全部节点。

- 取消保存对话框时不再询问导出范围；省略扩展名会自动补齐，输入其他格式的扩展名时提示修正。

- 子菜单跟随浅色、深色外壳主题，导出内容及文档主题不因界面主题而变化。

### TXT 大纲导出

- “文件 → 导出当前页为 TXT…”适用于当前主导图、子导图、详情页或想法，包含当前页折叠分支下的节点。只读页面可导出，空态禁用入口。

- 默认文件名为 `思维导图.txt`。选定文件后直接写出 UTF-8 文本，使用 LF 换行。每个节点占一行，根节点顶格，每深一层缩进一个 Tab。

- 每行只取节点正文，正文内的换行和 Tab 转成空格，再去除首尾空白。纯图片节点写作 `[图片]`，其余空白节点写作 `[空节点]`。

## 保存与关闭

### 显式保存与关闭

- **关闭标签：** 关闭标签前立即提交有效输入并保存，成功直接关闭，失败则保留标签并提示；不再显示保存／放弃确认。

- **批量关闭与退出：** 关闭其他标签和退出先保存全部目标，全部成功才关闭，任一失败则保留全部目标并定位失败文件。

- **输入法检查：** 显式保存先检查该文件全部标签的输入法候选，再提交有效输入；自动保存只保存已提交快照。

- **保存全部：** 保存全部按文件首次出现的编辑区标签顺序处理，每份文件只写一次，失败时停止；成功保持原活动标签。

- **资源释放：** 关闭标签断开其订阅并释放画布及面板，其他同文件标签继续可用；最后一个标签关闭后才停止文件级计时器并释放共享文档。

### 自动保存与后台写入

- 已提交的内容、节点样式、布局、折叠、导图主题及撤销重做采用500毫秒防抖自动保存。

- 原地文字在确认或失焦后提交；自动保存只读取已提交快照，不提交侧栏草稿、不关闭菜单和预览，也不打断输入法或清空历史。

- 超过 1000 个节点的标准原生文档由独立 Python 进程编码和原子写入，GUI 仅捕获稳定版本。

- 后台完成只标记捕获的文档代次及历史版本，期间的新修改继续保持未保存；显式保存、打开、改路径及关闭先等待已有写入。

- 小图、自定义写入器或编解码器、扩展实体以及直接调用 `autosave()` 保留同步保存语义；计时器调用 `autosave(background=True)`。

- 保存失败保留修改标记、原文件及内存内容，不循环弹窗重试；后续修改、手动保存、保存全部或关闭时可再次尝试。

- 打开 `.mindmap` 后沿用原路径自动保存；已删除有损导入后另存为的步骤及待导入状态。

- 显式保存和图形导出仍提交有效输入；保存和关闭会等待未完成的输入法候选。

## 面板、布局与视图

### 窗口停靠与默认布局

- 工作区菜单和算法选择入口已删除；树形布局、布局方向与紧凑布局仍然可用。

- 不再支持辅助工作区、浮动／独立面板、面板最大化和全部隐藏／恢复；窗口内停靠、临时展开和标签分屏保留。

- 拖到主窗口外释放会取消移动；旧多窗口会话加载时自动合并到主窗口，下次保存自然清除旧窗口字段。

- `Shift+F12` 恢复默认布局并保留全部当前导图和活动会话；主窗口的最小化、最大化与关闭继续正常工作。

- 中央标签保留关闭按钮和右键关闭操作，不再提供单独显示原导图的菜单入口。

### 初始画布与恢复定位

- 新建和手动打开导图时，等待画布及侧栏布局完成后以 100% 显示，并将根节点置于中央画布的可见区域中心。

- 隐藏标签首次显示时才完成定位；后续切换标签、重复打开已有文件及调整窗口或侧栏时保留用户的倍率和位置。

- 启动恢复的标签等待真实分屏视口完成定位，隐藏标签保留目标中心，初始100%居中不会覆盖上次视图；关闭及文档替换清理待恢复请求。

### 大纲层级

- **默认面板：** 大纲和节点属性使用 Alt+1、Alt+2，默认显示右侧节点属性和底部操作日志。

- 大纲标题栏的层级按钮提供“显示所有层”和“显示1层”至“显示9层”，根主题计为第1层，首次默认显示2层。

- 按钮使用低对比度线条图标，当前层级通过悬停提示和菜单勾选呈现。

- 图标大小与邻近工具协调，并与选项、收起按钮一起显示和隐藏，遵循悬停、活动状态及标题图标设置。

- 各会话独立保留层级和展开状态；最近选择的层级保存在本机，作为后续新建或打开导图的默认值。

- 重复选择可重新应用，菜单勾选表示该会话最后选择的预设。

- 画布选中隐藏主题不会自动展开大纲；结构编辑保留已有分支状态，新分支按预设初始化，替换整份导图时重新应用预设。

- 层级操作在只读模式下也可用，不改变画布折叠状态、导图文件、修改标记或撤销历史。

### 导图布局与外观

- 导图设置侧栏通过右侧按钮或 Alt+3 打开，与节点属性在右上停靠区域切换。

- 侧栏的“导图布局”分组提供双向、向右、向左、向下四种图形结构，主题间距提供紧凑、适中、宽松预设及水平、竖直输入。

- 间距按导图逻辑像素计算，数值最多一位小数，连续输入等待400毫秒或回车、失焦后提交；一次提交可整体撤销、重做并自动保存。

- 向下布局交换屏幕轴与父子、同级间距的对应，切换结构继续保留逻辑间距。

- 既有文件外观不变，查看侧栏不改写配置。

- 布局侧栏按活动标签或分屏同步，位置、宽度和展开状态随桌面布局恢复；恢复默认布局仍优先显示节点属性。

- 侧栏的“导图外观”分组提供整图连接线样式及导图主题，复用四列图形选择器和带图标的主题下拉框；自定义主题只显示状态，不会在查看时替换。

- “设置”仅保留应用外观与布局选项；滚轮、导图布局、连接线和导图主题均不再提供菜单入口，整图布局与外观通过侧栏调整。

### 滚轮与导航

- 滚轮通过状态栏按钮单击切换上下滚动与缩放，只切换图标，不保留选中高亮或下拉菜单；悬停提示显示当前模式、点击后的模式及 Ctrl＋滚轮始终缩放的说明。

- 滚轮是本机全局偏好，同步所有标签并在重启后恢复，不写入导图文件或撤销历史；只读和正文编辑期间仍可切换，不提交正文草稿。

- 右键菜单及视图菜单不再提供“聚焦此分支”“返回完整导图”，Ctrl+F 不绑定画布命令。

- Escape 取消原地文字编辑、拖动或关闭菜单，空闲时不改变视图；导航所需的临时显示状态继续保留。

- 隐藏活动面板后自动将焦点交还画布，F6 导航已删除。

### 顶栏与视图按钮

- 中央区采用顶栏融合布局：撤销、重做位于文档标签栏右侧；状态栏最右侧依次显示适应窗口、恢复默认尺寸、回到中心和滚轮行为四个纯图标按钮。

- 恢复默认尺寸使用“环形回转”图标，提示“恢复默认尺寸（100%）”；点击围绕当前视口中心恢复 100% 缩放，查看位置超出范围时沿用画布边界约束，无默认快捷键。

- 取消原来的第二行工具栏和画布浮条，画布直接接在标签栏下方；视图菜单不再重复提供适应窗口、回到中心入口，Ctrl+0 和 Home 快捷键继续使用。

- 状态栏按钮跟随当前活动标签或分屏，无活动导图时隐藏；三个视图按钮在正文编辑期间禁用，只读模式下可用。

- 临时状态消息不会遮挡按钮，普通／紧凑模式仍维持28／24逻辑像素状态栏高度。

### 编辑器外观

- 每个编辑分屏只保留外层圆角，画布顶部使用直角、零内边距，与标签栏通过细分隔线衔接。

- 浅色使用冷灰外壳、浅灰标签栏与纯白画布；深色使用深灰外壳、灰色标签栏与稍亮的深色画布。

- 标签撑满栏高，取消圆角和整圈描边；当前标签与画布同色，底部使用2像素蓝线标记。

- 文件图标为14逻辑像素，标题使用常规字重；普通／紧凑模式的标签栏高度分别为32／28逻辑像素。

- 按钮沿用原有动作、快捷键和只读限制，切换明暗主题、调整窗口尺寸或重开标签后继续可用，且不进入 PNG/SVG/PDF 导出。

## 状态栏统计

### 节点数量

- 左下角状态栏的节点数仅统计当前活动画布的本页节点，包含根节点、折叠节点和屏幕外节点；子导图、详情页分别统计，灵感页面仅统计当前打开的想法。

- 切换页面、标签或分屏，以及新增、删除、撤销和重做后同步更新节点数；折叠、缩放和滚动不改变统计范围。

### 文件大小与刷新

- 状态栏在节点数、选中数和保存状态之后显示当前文件的磁盘实际大小，例如“文件大小：12.3 KiB”。

- 大小使用1024进制的 B、KiB、MiB、GiB，字节显示整数，其余保留一位小数；待保存的编辑仍显示已落盘大小。

- 新建、打开、启动恢复、切换标签或分屏及保存完成后更新；保存失败时重新读取原文件，无法读取时显示“文件大小：未知”。

- 普通选中和界面刷新只读取会话缓存，不轮询磁盘；关闭全部导图后恢复欢迎提示，临时状态消息沿用现有展示方式。

## 本机配置与偏好

### 主题与配置位置

- **主题边界：** 外壳的应用主题与导图主题独立，窗口布局和滚轮偏好不进入导图文件。

- 本机布局与偏好位于 Qt 用户配置位置下的 `mindmap/mindmap-workbench/`；其中 `workbench-settings-v1.json` 的 `mindmap` 命名空间保存滚轮和大纲层级等偏好，`outline/display_depth` 的0表示所有层、1～9表示指定层数，缺失或非法值回退2层。

- **画布与导出底色：** 工作台画布的显示底色跟随外壳主题；导图主题仍决定节点、连接线及 PNG/SVG/PDF 导出的背景，不因切换外壳主题而改写。

### 共享粘贴偏好

- 亿图、缩进文本和 Markdown 共用粘贴方式、保留原后代和替换根节点三项偏好，继续保存在 `clipboard/edraw_mode`、`clipboard/edraw_keep_children`、`clipboard/edraw_replace_root`，无需迁移旧配置。

- 每次有效粘贴均显示对应来源标题的配置弹窗；单根成功确认后，三种来源相互继承选择，同步所有会话并在重启后恢复。

- 根节点指当前选中的目标主题；选择保留时维持其文字和格式，仅导入复制内容的子树。

- 首次默认替换根节点，旧配置缺少此项或值无效时也使用此默认值；取消、失败及多根来源强制追加不改写单树偏好。

- 灵感区无选择时直接创建游离树，不显示配置且不更新偏好；文字编辑中的普通文本粘贴仍由编辑器处理。

### 退出记录与兼容

- `workbench-state-v1.json` 保存最近资源及退出视图；`plugins.mindmap.page_history` 保存页面访问记录，`views` 条目包含带版本的 `view_state`。旧 `documents-v1.json` 仅只读导入一次。

- 视图记录包含 `page_id`、`zoom`、场景坐标 `center`、`selection` 和导航临时范围 `focus_id`，不含Qt对象或其他页面缓存；配置继续使用版本1，旧记录缺少视图时从主导图默认视图开始。

- 布局文件继续只保存外壳，不保存导图路径、页面视图或内容。

- 最近文件更新后立即原子写入；退出快照在全部保存检查和关闭检查通过后、会话资源释放前提交，重复清理不会覆盖为空快照。

- 文档记录与布局配置分别校验，任一损坏均不妨碍另一部分恢复；没有既有记录的首次启动保持空白页。

- 导图内容继续保存在原版本4 `.mindmap` 文件中，页面导航、选择及视口不修改导图文件或历史；内存编辑草稿及撤销历史不写入退出记录。

- 页面恢复只保证正常退出时的快照，不提供崩溃恢复。

- 退出保存或输入法检查失败不覆盖旧快照；另存为后退出记录使用成功绑定的新路径。

## 操作日志

### 面板入口与布局

- “操作日志”默认在底部展开，高度为260逻辑像素。

- 通过停靠栏按钮、主菜单“视图”中的“操作日志”或 `Alt+5` 切换；可以收起、拖动及调整尺寸，位置、尺寸与显隐随本机布局保存。

- 旧布局首次加载时补齐日志面板；关闭全部导图后仍能查看本次运行的日志。

### 记录展示与文件来源

- 记录以紧凑列表按发生顺序追加，时间使用弱化的等宽文字，操作名称加粗，对象说明作为次要信息，右侧以标签显示文件名。

- 普通记录用柔和圆点标识，错误使用红色图形和浅底，警告使用三角图形与警告色；不再逐行堆叠“信息”前缀。

- 完整路径、级别及省略的长文字放入悬停详情，复制时仍保留 `时间 [级别] [文件名或应用] 操作说明` 的完整纯文本。

- 侧栏变窄时自动隐藏文件标签或时间，优先保留操作与说明，完整内容始终可通过悬停查看。

- 窗口统一记录所有标签及分屏的操作，文件名与完整来源路径在记录当时固定；标签切换及另存为不会改写旧记录的来源。

- 新建、打开、重复打开已有文件、关闭、手动保存、另存为、保存全部、PNG/SVG/PDF 和 TXT 导出均在操作完成后记录结果，取消对话框不记录成功。

- 失败保留原状态栏提示，并记录一次错误。

### 事件与记录范围

- 节点增删改、移动、粘贴、图片、折叠、样式、布局、导图主题、子导图及详情页修改从已提交的引擎事件生成中文摘要。

- 一次批量事务只记一条，撤销和重做注明对应操作；试算、回滚及没有实际变化的编辑不记成功。

- 自动保存成功不记录，同步及后台保存失败都记录所属文件；普通选中、缩放、平移、页面跳转及标签切换不记录。

### 新增与删除摘要

- 新增节点说明节点名称及实际父节点，例如 `新增子节点：在「人文学科」下新增节点「哲学」`。

- 新增同级节点显示共同父节点；插入父节点说明新节点归属，并保留已有节点改挂到新父节点的移动说明。

- 粘贴分支同时注明新增总数，图片等无文字节点使用短标识区分。

- 删除叶子节点显示原父节点和名称，删除分支显示例如 `删除节点：从「人文学科」下删除分支「哲学」，共删除4个节点`。

- 总数包含分支根、全部普通后代及连带删除的子导图、详情页节点，折叠隐藏的节点也计入；发生结构变化但仍保留的父节点和图片资源对象不计入。

- 多选祖先与后代、重复选择均按实际删除的节点 ID 去重，只列独立分支根及各自父节点，最多列三处并提示其余处数，总数始终覆盖本次全部增删。

- 单独删除子导图或详情页时，用“入口”说明归属并统计页面实际移除的节点。

- 撤销删除写成“恢复”并注明恢复数量，撤销新增说明实际删除内容；重做按实际方向描述。

- 名称和归属均从提交时快照读取，后续改名或删除不改写旧日志。

### 移动摘要

- 拖动摘要明确描述实际移动对象、原父节点与新父节点，例如：`拖动节点：将「哲学」从「第二大脑」移到「07.人文学科」下`。

- 同父节点排序显示 `「哲学」在「人文学科」下由第3项调整为第1项`，左右换边显示 `「哲学」在「第二大脑」下从右侧移到左侧`；排序与换边同时发生时一并说明。

- 同级序号按各自父节点的子列表从1开始计算，方向使用实际解析后的左右侧。

- 撤销交换来源与去向并注明“移回”，重做注明再次移动；历史名称取提交时快照，不随后续改名变化。

- 多选一次拖动仍为一条日志，逐个说明独立移动根节点，随行后代和普通兄弟不重复计算。

- 无文字节点使用“无文字节点（短标识）”区分，旧事件没有移动信息时保留通用摘要，不猜测具体拖动对象。

### 文字修改摘要

- 修改正文显示明确的前后内容，例如 `修改节点文字：从「哲学」改为「哲学导论」`。

- 撤销交换前后值，重做按再次修改的方向显示；未提交草稿、取消编辑及相同内容的提交不产生成功记录。

- 空文字显示“（空内容）”，换行、制表符分别显示为 `↵`、`⇥`，避免换行与空格的修改看起来没有变化。

- 长文字在单条2048字符上限内均分前后内容的展示预算，并保留首次差异附近的上下文，省略处以“…”标识，防止新内容被长旧值挤掉。

- 批量修改保持一条记录，最多展示三组不同的前后内容并提示剩余组数；入口与附属页名称同步产生的相同修改合并展示。

- 内容来自提交时的差量快照，后续修改或删除不改写旧日志。

### 复制、滚动与保留范围

- 支持单选、`Ctrl`／`Shift` 多选记录，按 `Ctrl+C` 或右键复制所选记录的完整文本，`Ctrl+A` 选择全部；复制顺序始终按发生时间排列。

- 标题栏以复制和垃圾桶线条图标提供“复制全部”和“清空”，悬停显示中文提示，右键菜单保留同名文字入口。

- 处于日志底部时自动跟随新记录，浏览历史时保留原位置；隐藏面板仍继续记录，追加不抢焦点、不强制展开。

- 只保留内存中的最近1000条文字摘要，重启后清空，不生成磁盘日志，也不进入 `.mindmap`、退出会话记录或图形导出。

### 公开记录接口

- 工作台公开 `record_operation(message, *, session=None, level="info")`，返回 `None`，须在 Qt GUI 线程调用。

- `message` 为中文摘要；`session` 接受所属 `MindMapEditorView`、尚未建立会话的文件路径（字符串或 `Path`），或代表应用级事件的 `None`。

- 来源在调用时转换为文件名，不保留会话引用。

- `level` 接受 `info`、`warning`、`error`，分别显示为“信息”“警告”“错误”；已释放的窗口或会话忽略迟到记录。

- 每条摘要最多2048个字符，换行转换为空格，防止多行文本挤占条目上限；记录接口不修改导图、历史、活动标签或焦点。

- `OperationLogPanel.plain_text()` 返回当前全部记录的完整纯文本，不修改选择、滚动或剪贴板。

## 收藏侧栏

### 入口与浏览

- 左侧“收藏”按钮或 `Alt+4` 切换收藏侧栏，默认位于大纲之后、首次收起；停靠位置、尺寸及展开状态随本机布局保存。

- 列表按最新收藏在前显示名称与页面层级路径，单击或 Enter 恢复目标页现场，当前页高亮，右键可取消收藏。

- 仅子导图支持收藏，入口为路径栏右端星标和入口节点右键菜单；只读仍可浏览和跳转。

### 会话职责与文件保存

- 每个 `MindMapEditorView` 拥有独立的 `favorites: SubmapFavoritesPanel`，工作台通过共享堆叠容器切换活动会话的列表。

- 收藏面板不扩展原三个面板组合的宿主协议，会话负责安全导航、草稿及输入法检查、权限同步、主题映射和释放，空白页显示“没有打开的导图”。

- 收藏随原 `.mindmap` 文件保存，享有既有自动保存、重试、另存为、撤销重做及退出保存行为；`preferences.ini` 和 `documents-v1.json` 不保存收藏内容。

- 重启后恢复最后所在页，列表从文件恢复并同步当前页高亮；复制粘贴分支创建的新页面不继承收藏，复制整份文件保留收藏。

## 多会话接入接口

### 文档、视图与平台

- `views.py` 中的 `MindMapEditorView` 实现编辑器视图，`documents.py` 中的 `MindMapDocumentHandle` 持有共享引擎、文件状态、自动保存计时器和后台任务；`editor_provider.py` 负责创建与登记。
- 通过 `window.documents.active` 获取活动视图。导图专属面板和会话管理可通过 `window.plugins.instance("mindmap")` 查询；通用窗口没有导图属性转发。
- 复制标签共享文档和历史，各视图独立保存页面、导航、选择和缩放；共享状态通过 `view.document` 读取。
- 新建、打开、保存全部、恢复和两阶段关闭由工作台文档服务协调。插件只实现文件保存、视图输入提交与业务状态恢复。

### 页面历史与写入

- `PageHistoryState` 仅管理按文件隔离的最近页面，通过插件状态服务持久化，保留每文件最多 50 项及失败重试。
- 最近文件、退出视图和活动标签由平台管理；旧文档记录只由产品迁移层读取。规范化路径使用公开 API，Windows 按系统规则忽略大小写。
- 自动保存使用文件级快照和原子替换；成功保存后才同步改绑路径，未完成的输入法候选阻止保存和关闭。
- 启动先注册编辑器或占位页，再恢复布局；原标签标识与分屏引用保持稳定。
