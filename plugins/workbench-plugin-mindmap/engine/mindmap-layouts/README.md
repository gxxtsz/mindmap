# mindmap-layouts

内置布局能力包，仅依赖 `mindmap-core`。一个确定性的树布局算法支持左、右、双向、向下四种方向。

## 快速接入

```python
from mindmap_core import MindMapDocument
from mindmap_layouts import create_default_layout_registry

document = MindMapDocument.new("中心主题")
registry = create_default_layout_registry()
result = registry.layout(document)
```

- **节点测量：** 真实图形界面应传入包含文字、标签及图片的完整节点尺寸。省略测量时使用近似值。

- **实例与扩展：** 聚焦、临时展开和导出均不改变文档。每次工厂调用返回独立实例，宿主可以继续注册自定义算法。

- **输入隔离：** 默认工厂将受控的内置树布局注册为只读实现，避免布局前再次深拷贝整图；第三方注册仍默认隔离输入。

- **布局缓存：** 同一实例缓存最近一次几何计算，复用拖动试算、正式提交及相同尺寸下的布局；每次返回独立结果映射，调用方修改结果不会污染缓存。

## 连接线路由

- **分支样式：** 内置树布局声明支持分支样式，节点矩形排布完成后由 `connectors` 统一生成 11 种连接线。

- **路由入口：** `route_branch` 提供单边路由；`route_branches` 按父主题设置批量路由并去除相同画笔的重复直主干。

- **方向与兼容：** 左向镜像，向下转置，双向按实际左右位置分组；未配置样式时保持旧 `Curve` 及其控制点。

- **公式与参数：** 普通弧线、坡度曲线和圆角采用已恢复公式；主干比例、短边保护、箭头尺寸及第 11 类参数为独立重建。

## 主题间距

- **配置范围：** `LayoutConfig.options` 支持 `level_gap`（父子间距，24～500）和 `sibling_gap`（同级子树间距，4～500），单位为导图逻辑像素。

- **参数校验：** 仅接受有限数值，拒绝布尔值和未知键；方向只决定坐标转置，不改变参数含义。

- **公开解析入口：** 公开接口 `resolve_tree_spacing(config) -> tuple[float, float]` 返回两个有效间距，完整布局、增量几何和界面复用该入口。

- **缺省与覆盖：** 缺省值依照旧 `compact` 标记解析为32／10或64／22，不修改原配置；显式参数逐项覆盖缺省值。

- **文件与缓存：** 新参数保存在现有原生格式的 options 中，文件格式版本不变；完整布局缓存包含有效间距，避免修改后复用旧几何。

## 正式画布增量几何

### 持久化几何

- `mindmap_layouts.incremental.IncrementalTreeGeometry` 已接入正式画布，维护子树摘要、持久化同级索引及分层视口查询，支持四方向、折叠、变尺寸和子树移动。

- `snapshot()` 共享不可变树根，后续更新不会改写旧版本；`rectangle()` 按父链解析坐标，`query()` 仅遍历与视口有关的区域，`all_rectangles()` 显式生成完整坐标。

### 稳定布局结果

- `mindmap_layouts.incremental_result.IncrementalTreeLayout` 组合测量、分支样式摘要、局部路由缓存及惰性 `LayoutResult`。

- `update()` 只接收变化节点，`result()` 返回稳定布局版本；节点和连接线映射支持完整枚举，但交互期间应使用视口查询，避免主动展开全图数据。

- 连接线按父级局部坐标缓存，平移时仅更新世界原点，保留主干去重和绘制顺序。

### 优化边界

- 默认注册表的 `TreeLayout` 继续返回原有完整结果，供扩展、聚焦和导出使用。

- 正式画布只为未被覆写的内置树布局启用增量服务，第三方算法保留隔离与完整校验。

- 首次加载、全局配置变化及完整输出仍需处理整图。

### 宿主能力查询

- 宿主通过公开的 `supports_incremental_layout(registry, algorithm_id)` 查询优化能力，再调用 `create_incremental_layout(registry, document, measurements)` 创建独立增量服务。

- 文档须为已校验的引擎快照，测量表须包含全部节点尺寸；不支持的实现返回 `None`，调用方继续使用注入的 `registry.layout()`。

- 注册表子类、算法子类和被替换的方法入口均保留完整调度，因此显示、编辑校验与导出会一致地经过宿主扩展。

- Qt 层不自行检查具体类型或实例私有状态；聚焦模式继续使用完整布局。

### 视口与同级邻居

- `query_with_sibling_neighbors(viewport, skipped_ids=())` 查询世界坐标视口及相邻同级节点，四方向的坐标变换与索引查询由服务封装。

- skipped_ids 只影响寻找邻居，不过滤视口命中节点；仅要求成员判断协议，可使用惰性移动子树集合，不会为了查询展开整个集合。

- 返回新的节点到不可变矩形映射，不暴露内部同级索引，也不修改文档或几何版本。
