# 思维导图应用层

`mindmap-application` 装配唯一的思维导图主体，提供文档会话、页内导航、业务面板、操作日志和自动保存。代码位于 `src/mindmap_application/`，由产品的应用工厂直接构造，通过内部桌面协议使用窗口、标签与分屏基础设施。

## 文档和页面

每个导图目录按绝对路径对应一份共享引擎、撤销历史和保存状态。每个标签独立持有画布及视口，树页和图页通过同一个画布切换。复制标签时复用文档并复制当前页视图。

`MindMapEditorView.widget` 是 `NodePageHost`。普通导图通过 `canvas` 显示，专用详情通过 `pages` 进入，始终留在同一标签。扩展页内只提供自身业务控件；保存、撤销和重做仍由导图处理。节点属性及导图设置在扩展页期间暂时收起，避免误改隐藏画布。

最近访问记录树页、节点图及外部专用详情页。图页空白处和节点的右键菜单提供「DOT 自动布局」。状态栏显示节点与连线的选择数量，并提供缩放和滚轮按钮。删除图时返回所属节点，入口被删除时回退到仍有效的祖先页。

## 扩展发现

应用层按 `mindmap.node_pages` 入口点构造 `NodePageRegistry`，也可通过 `options["page_registry"]` 注入自定义注册表。此选项只配置节点页面注册表。

扩展只能读写所属节点的业务数据。未安装、版本不支持或初始化失败时显示保留提示，其他导图功能继续可用。

## 保存

导图绑定目录后防抖自动保存，大图在后台进程提交快照。多个标签共享保存状态与外部修改冲突检测。复制、切换、保存和关闭统一检查输入法及待提交属性，关闭失败时保留原标签。

新建、打开、保存和导出仍通过现有文件控制器执行。扩展不能改绑路径或直接保存另一份业务文件。

## Git 同步

`GitSyncController` 将活动文档绑定到顶栏控件。保存通知触发本地检查，远程检查独立轮询，工作线程只接触路径、Git 状态及目录版本。只有确实修改工作区或写提交时才暂停同一导图的编辑；快进和提交在目录版本校验及写入锁内完成。快进后的重载使用文件控制器的校验流程，并恢复各标签的页面和视口。各项操作的使用方式见[主说明](../../README.md#git-同步)。

定时同步按共享文档登记，开关按规范化的目录路径保存在本机。调度器在同一路径的 Git 任务结束后处理到期请求。关闭最后一个标签、另存或关闭开关会使旧登记失效。每次派发写入前复核登记和共享文档状态，已快进的磁盘版本仍完成重载校验。后台线程读取校验凭据及目录版本，界面线程接管文档并恢复各视图。
