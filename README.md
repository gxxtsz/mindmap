# 思维导图

基于 Python、PySide6 和 uv 工作区的本地思维导图应用。可以用树组织主题，在任意文字节点上挂载一张有向图。

## 启动

支持 Python 3.12 和 3.13。首次使用先克隆仓库：

```powershell
git clone https://github.com/gxxtsz/mindmap.git
cd mindmap
```

在仓库根目录安装依赖并启动：

```powershell
uv sync --locked --all-packages --group dev
uv run --locked --package mindmap-app mindmap
```

也可运行 `uv run --locked --package mindmap-app python -m mindmap_app`。

| 参数 | 用途 |
| --- | --- |
| 目录路径 | 打开包含 `mindmap.json` 的导图目录 |
| `--theme light\|dark` | 指定主题 |
| `--state-dir 目录` | 使用独立配置目录 |
| `--no-restore` | 跳过上次标签和布局恢复 |
| `--compact` | 使用紧凑外壳 |
| `--size 宽x高` | 指定窗口尺寸 |
| `--screenshot 文件.png` | 保存窗口截图和元数据后退出 |

## 页面前进和后退

在主窗口按鼠标后退键，可回到当前标签上一次访问的页面。按前进键可沿原访问顺序再次打开页面。主导图、子导图、详情页、节点图、扩展详情和独立想法都支持侧键切换。

后退后打开其他页面，会替换原来的前进记录。每个标签独立记录，重开、复制或重载时以当前显示的页面为起点。

## 节点文字与宽度

- 导图和节点图中新建的文字节点默认渲染 Markdown。双击正文或按 F2 编辑源码，按 `Shift+Enter` 换行。右键可切换「显示为纯文本」或「渲染为 Markdown」。已有节点按保存的格式显示。
- 编辑 Markdown 节点时，网页中的标题、列表、代码块、表格和带 TeX 注解的公式会转成 Markdown 源码。围栏代码可指定语言以启用语法高亮。
- 数学公式支持行内 `$...$`、`\(...\)` 和独立的 `$$...$$`、`\[...\]`。公式在本地排版，可用于画布和图形导出。
- 单选文字节点，沿水平方向拖动右下角手柄。拖动时可查看新的换行和高度，松手后更新布局。右键选择「恢复自动宽度」会按内容重新测量。
- 格式和固定宽度随导图保存，也可以撤销或重做。PNG、SVG、PDF 使用已提交的节点排版。

## 节点图

1. 选中文字节点，从编辑菜单或节点右键菜单选择「添加图」。已有图时可以选择「打开图」或点击节点上的图标。
2. 在图页按 Tab 或 Enter 添加节点，或从右键菜单选择「编辑图文本…」粘贴整张图。拖动节点可调整位置，双击或按 F2 可编辑标题。
3. 从画布或组内空白处按住左键拖框，可同时选中节点和连线。拖动时高亮和状态栏计数随选框更新。选中的连线会加粗，所选节点的其他关联线用主题色提示。选框碰到可见卡片、线身或箭头即可选中，完整包住组框才选中组本身。按 Esc 取消本次框选。
4. Ctrl 点击可逐个增减，Ctrl 拖框可追加选择。Shift 从空白处拖框只选连线，Ctrl+Shift 拖框可追加连线。按 Delete 或右键「删除所选」可一起删除，Ctrl+Z 一步撤销。删除节点也会删除它的关联线。
5. 右键图页空白处或普通节点，选择「整图自动布局」。布局从最内层排到顶层，每个组以完整外框占位。
6. 点击路径栏的返回按钮回到所属节点。图随导图目录自动保存，可以撤销、重做和在多个标签中同步编辑。

选中至少两个同层节点，按 Ctrl+G 或右键选择「编组」。组框会在原地出现，直接输入组名并按 Enter，按 Esc 可保留默认名。点击标题栏或边框选中整组，拖动标题栏移动整组，双击组名或按 F2 改名。组标题也可添加附件、详情页、子导图和下级图。

双击组内空白或右键选择「新建组内节点」，可以在该位置添加成员。普通拖动时，指针旁会显示松手后的归属，多选节点会一起移入同一个组。无法转接的连线或分组循环会在松手前提示。按住 Shift 拖动可保留各自的归属，自由叠放。松开 Shift 会立即恢复入组预览。最近拖动的对象显示在同层最前方，Esc 可取消本次拖动。

右键顶层空白或顶层普通节点，选择「顶层自动布局」可整理顶层对象，每个组带着全部成员和内部连线一起移动。右键组标题、边框或组内空白，选择「组内自动布局」只整理直属成员。两种局部布局都保留当前缩放和视口位置。选中组后拖右下角手柄可设定最小宽高，「恢复自动大小」清除下限。

图中只连接同层节点。编组时，对外连接转接到组框，同向同端点的多条连线只显示为一条箭头。按 Ctrl+Shift+G 或选择「解除分组」可将成员提到父层并还原原端点。纯标题随组框移除，有独立连线、附件或附页的标题转为普通节点。主动改接的组级线归标题，主动删除的线同时清除还原记录。「删除整组」在确认时显示成员数量。

图文本用 `节点 g1 "核心模块"` 定义组节点，用 `分组 g1 app core` 指定成员。自动生成的 `来源 g1 out app out` 表示 `g1 -> out` 转接自 `app -> out`，复制图文本时带上这些行即可保留还原信息。

## 节点附件

把单个本地文件拖到导图或节点图的节点上即可导入。普通文件作为附件保存，每个节点保留一个附件，再次拖入时可确认替换，右键选择「移除附件」可清除关联。这些操作都可以撤销和重做。

单击节点上的回形针会使用系统默认应用打开附件副本。若要将外部应用中的修改保存回导图，可把编辑后的文件拖回节点并确认替换。

## SVG 图片节点

把 `.svg` 文件拖到节点上即可在画布中显示图片。导图会展开落点节点并追加图片子节点，节点图会从落点自动连线到新图片。选中图片后可以拖动边缘手柄等比缩放。

SVG 随导图保存，重新打开时可以直接显示。图像以静态方式绘制，SVG 引用的外部图片需先嵌入文件。

## 代码结构

```text
apps/mindmap-app/                  产品启动、直接装配、历史数据迁移
mindmap/
  core/                           节点模型、事务、布局、历史、原生格式
  qt-render/                      静态绘制、节点测量、图形导出
  qt-editor/                      导图画布、面板、节点页面协议与容器
  application/                    导图应用、文档会话、导航、自动保存
packages/
  mindmap-desktop-api/             导图应用与桌面的内部协议
  mindmap-desktop-runtime/         窗口、标签、分屏、配置、日志基础设施
```

7 个分发包共用一个工作区和锁文件。产品入口直接构造导图应用和桌面运行时。

## 保存与会话

「打开导图」选择导图目录，也可以将目录拖进窗口，或把目录路径附在启动命令末尾。「新建」和「另存为」先选择父目录，再输入导图目录名。

- `mindmap.json` 保存版本、主导图入口、页面索引、全局设置和资源清单。
- `pages/` 为主图、灵感区、子导图和详情页各保存一个 JSON。图节点的数据保存在所属页面。
- `assets/` 按 SHA-256 保存图片和文件附件的原始字节，没有资源时可省略此目录。

可以用 Git 跟踪上述内容。应用只替换有变化的文件。若目录作为 Git 工作区使用，可在其根目录将 JSON 的换行固定为 LF，并让 Git 按二进制跟踪资源。在应用关闭导图后切换分支，可以让应用下次直接读取该分支的内容。编辑期间若发现磁盘变化，「文件」菜单可重新加载磁盘内容或将本地修改另存为。

```gitattributes
/mindmap.json text eol=lf
/pages/*.json text eol=lf
/assets/* binary
```

本机配置位于系统配置目录的 `mindmap` 下。`mindmap-state-v2.json` 保存导图标签、导航与分屏，`mindmap-settings-v1.json` 保存窗口和导图偏好。

## Git 同步

安装 Git，并让导图目录本身成为 Git 仓库、当前分支跟踪远程上游。打开导图后，顶部「Git 同步」显示待保存、未提交、待推送和远程更新情况。保存后立即检查本地，外部 Git 操作约两秒内反映。远程状态每 30 秒刷新一次，也可点击「立即检查」。

在「Git 同步」菜单勾选「每小时自动同步」，为当前导图启用定时同步。开关默认关闭，按目录保存在本机。勾选或重新打开导图后，满一小时开始首轮，之后每小时检查一次。后台标签同样参与，同一导图的多个标签共用一份计时。

自动同步会提交已保存的导图文件，并推送当前分支的待推送提交。只有远程领先且本地工作区干净时，才自动快进并更新各标签。遇到编辑或保存进行中、两端分叉、保存冲突或远程不可用时，本轮跳过写入。推送失败会保留本地提交。更新、推送及失败原因可在操作日志中查看。

- **更新导图**：本地工作区干净、分支只落后于远程时可用。更新成功后，各标签回到原来的页面和视口；页面已经删除时回到主图。
- 「提交并推送」会保存编辑，用「更新导图」作为提交说明，仅提交导图清单、页面和资源，然后推送至当前分支的上游。其他文件的暂存内容保持原样。推送失败时保留本地提交，可再次点击「推送」。
- **仅提交**：只在本地留下提交。两端都有修改时可以先用此操作保留本地版本，再在 Git 中处理分叉，处理后重新检查。应用不会自动合并或覆盖。

远程不可用时仍可本地编辑、保存和提交。应用使用系统已配置的 Git 凭据；如遇认证失败，请先在终端确认该仓库的 Git 拉取权限。若 Git 已更新但导图加载失败，可在「文件 → 处理保存冲突」重新加载磁盘版本或将当前导图另存为。
