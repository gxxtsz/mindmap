# 原生思维导图

使用 Python、PySide6 与 uv workspace 构建的思维导图引擎及多导图桌面工作台。
工作台支持 Python 3.12、3.13；当前工作区使用 Python 3.12，锁定 PySide6 6.12.0。
三个引擎包的 Python 要求为 3.12+，不依赖 Qt 或桌面框架。

## 快速开始

克隆本仓库后直接在根目录执行，全部基础包均包含在当前工作区：

```powershell
uv sync --locked --all-packages --group dev
uv run --locked --package mindmap-workbench mindmap-workbench
```

也可在启动时打开指定的 `.mindmap` 导图：

```powershell
uv run --locked --package mindmap-workbench mindmap-workbench 我的导图.mindmap
```

各成员通过 workspace 引用本仓库源码，普通源码更新后重启工作台即可使用；依赖或包元数据更新后重新同步。
工作台支持 `--theme light|dark`、`--state-dir`、`--no-restore`、`--compact`、
`--size` 和 `--screenshot`，详细用法可执行
`uv run --locked --package mindmap-workbench mindmap-workbench --help` 查看。

## 当前功能

支持节点编辑、11 种分支连接线、四方向树布局、图片、复制粘贴、撤销重做和 PNG/SVG/PDF 导出。
Ctrl+V 和右键“粘贴”支持自动识别缩进大纲：一行一个节点，Tab 或每级 2／4 空格表示层级，多个顶层节点并列追加。
允许能够唯一确定层级的 Tab／空格混用；空行忽略，整段共同缩进自动去除，缩进错误或歧义提示原文行号，失败不改变导图。
整次大纲粘贴可以一次撤销、重做；Markdown 标题和列表继续自动识别，文字编辑期间仍直接粘贴正文。
选中节点后可用 Ctrl+V 或右键“粘贴”添加纯图片子节点，多选只处理按树顺序排列的第一个父节点；本地和网址导入采用相同方式。
新图片节点按原始像素尺寸显示，不带正文、背景和常驻边框；单选后拖动四边或四角可等比调整显示尺寸，原始图片数据不变。
图片节点可以拥有普通子节点，不能拥有详情页或子导图。详情页入口可以添加图片子节点，子导图入口需先进入子导图添加；旧图文节点保持原样。
文字编辑期间也可粘贴图片，先提交有效正文；输入法候选未完成时保留草稿并提示，只读模式禁止修改图片。
图片随导图保存，支持撤销、重做及自动保存；复制图片文件路径或网址仍按原有文本规则粘贴。
节点可整条分支拖动，支持同级排序、改挂父节点及吸附、插入提示；双向布局还支持一级分支左右换边。
拖到节点正文可接为子主题，拖到节点外的间隙可插入同级，文字提示会明确显示松手后的操作。
拖动时其他节点保持原位，松手后以 140 毫秒动画重排；超过 500 个可见节点时直接显示最终位置，避免全图逐帧更新。
折叠目标也在放下后展开；一次拖动只提交一条撤销记录。
靠近画布边缘时自动滚动，Esc 取消；拖动提示不影响自动保存和导出。
新建导图默认使用圆角正交连接线，新增主题沿用父主题样式；打开已有文件保留其原有外观。
支持从亿图脑图复制主题或分支后通过 Ctrl+V 粘贴，仅导入文字、层级与同级顺序，外观沿用本项目配置。
亿图、缩进文本和 Markdown 共用粘贴配置：可选择追加或替换目标节点，替换时可分别选择是否替换根节点、是否保留原后代；多个并列来源主题仅支持追加。
根节点指当前选中的目标主题；选择保留时维持其文字和格式，仅导入复制内容的子树，首次默认替换根节点。
三种来源每次有效粘贴均显示选项，工作台共享上次成功的单根选择，同步所有会话并在重启后恢复；整个粘贴操作可一次撤销、重做。
灵感区无选择时直接创建游离树，不显示配置；取消、失败及多根强制追加不覆盖单根偏好。
桌面应用采用单主窗口，提供可拖动的工具面板按钮，大纲和节点属性可停靠到左、右、底部或在主窗口内临时展开。
底部默认展开“操作日志”，通过面板按钮、视图菜单或 Alt+5 切换，可拖动、调整高度并记住布局；空白页也可查看。
日志统一记录各导图的主要文件操作、已提交编辑和失败原因，注明时间、级别与所属文件；批量操作一条记录，撤销重做注明原操作。
新增、删除日志明确节点名称和所属父节点；删除分支统计根节点、全部后代及连带页面节点，重叠选择按实际节点去重，撤销时注明恢复数量。
移动日志明确被移动节点与前后父级，同级调整显示序号，换边显示方向；撤销、重做按实际移动方向描述。
修改文字的日志显示修改前后的内容，撤销、重做按实际方向排列；空内容及换行显式标注，长文字保留差异附近的上下文。
自动保存只记录失败，普通选中、缩放、平移及标签切换不记录；面板隐藏时继续记录，追加内容不抢焦点。
日志按时间、状态图形、操作、对象及文件标签分层显示，完整路径与长内容放入悬停详情；异常使用红色或警告色标识。
标题栏用图标提供复制全部和清空，列表支持 Ctrl／Shift 多选及 Ctrl+C 复制完整记录；最多保留本次运行的最近1000条，重启清空，不写入导图或本机日志文件。
右上角最小化按钮左侧提供图钉按钮，点击置顶整个主窗口，再次点击取消；启用时使用主题高亮。
置顶状态保存在本机 `preferences.ini` 的 `window/always_on_top`，重启后恢复，首次使用默认关闭。
`--no-restore` 跳过导图及布局恢复时仍保留这项窗口偏好，空白页也可以切换置顶。
界面采用中性外围、独立圆角卡片和窄间隙，菜单、侧栏、临时展开面板及应用自有弹窗统一适配明暗主题。
外壳主题与导图主题独立；画布显示底色跟随外壳，导出使用导图主题，界面装饰不进入 PNG、SVG、PDF 导出。
属性侧栏自动提交，支持多选样式及分支批量编辑；面板位置、尺寸和展开状态保存在本机。
节点属性按字体、主题、分支纵向分组，无 Tab 或内容编辑字段；支持字体搜索、色块选择及自定义最大文本宽度。
节点属性的“分支”分组提供四列图形选择器，可选择“整个子树”或“仅本级”；未设置样式的节点保留原有曲线。
导图设置侧栏通过右侧按钮或 Alt+3 打开，与节点属性共用右侧区域。
侧栏提供四种布局结构的图形选择，以及紧凑、适中、宽松三个主题间距预设和水平、竖直数值输入。
间距按导图逻辑像素计算，向下布局按画布实际坐标轴显示；数值等待400毫秒或回车、失焦后提交，支持撤销、自动保存及多导图独立设置。
既有文件保持原有间距，查看侧栏不补写默认值；侧栏的“导图外观”分组提供整图连接线样式及导图主题，主菜单不再提供这些导图设置入口。
全局分支设置覆盖整张导图，后续新增节点沿用父节点样式；节点属性仍可单独设置局部分支。
中央文档标签栏右侧提供撤销、重做；状态栏最右侧依次提供适应窗口、恢复默认尺寸、回到中心和滚轮行为四个纯图标按钮。
恢复默认尺寸使用“环形回转”图标，点击恢复至 100% 缩放，围绕当前视口中心调整，查看位置超出范围时沿用画布边界约束。
三个视图按钮复用活动画布动作和启用状态，不再显示画布浮条或对应视图菜单入口；按钮适配明暗主题及紧凑模式，不进入图形导出。
滚轮按钮单击在上下滚动与缩放间切换，只切换图标，不保持选中高亮，也不弹出菜单；悬停提示说明当前模式和下一步行为，Ctrl＋滚轮始终缩放。
通过侧边按钮、编辑菜单或 Alt+2 打开属性侧栏。
画布隐藏两条滚动条，随可见节点和图片自动扩展、收缩，四周各保留一屏操作余量。
新建和手动打开导图按 100% 原始大小显示，根节点居于可见画布中央；“适应窗口”按内容居中，倍率限制为 10%～200%。
超大导图达到 10% 下限后停止缩小，超出窗口的部分可通过拖动查看。

单主窗口支持多个独立导图标签及分屏，各自保留历史、选择、视口、临时导航和只读状态。
首次启动和关闭全部标签后显示“新建导图／打开文件”空白页；新建先选择位置，首次写入成功才创建标签。
不同文件始终新增标签；相同规范化绝对路径只激活已有标签，不重新加载或改变分屏位置。
内容、样式、折叠、布局、导图主题及撤销重做在提交后以500毫秒防抖自动保存，选择、缩放和平移不写文件。
“保存全部”使用 Ctrl+Alt+S，按标签顺序提交有效输入并保存；关闭和退出先保存，失败时保留目标标签及内存内容。
文件打开、新建、保存、保存全部、另存为和自动保存仅支持 `.mindmap` 原生导图。
保存时省略扩展名会补齐 `.mindmap`，输入其他扩展名直接提示修正，不改名或写入其他格式。
主菜单右侧仅显示当前导图名称及下拉箭头，悬停或展开时显示灰底；点击可查看最近20个文件及所在目录，长名称省略，悬停显示完整路径。
成功新建、打开、重复打开或另存为后更新历史，普通标签切换和自动保存不改变排序；清空最近记录不关闭导图，也不影响启动恢复。
默认启动时重开上次正常退出时打开的全部导图，恢复标签顺序、分屏位置和活动项；已关闭的标签不会重开。
每份文件恢复退出时当前的主导图、子导图或详情页，以及该页的缩放、画布位置、节点选择和导航临时显示范围。
隐藏标签首次显示后完成定位，其他已访问页的视图缓存不落盘；手动关闭标签后重开仍从主导图默认视图开始。
缺失或损坏文件跳过并汇总提示，其他导图继续恢复；文件仍保留在最近列表中供重试。
`--no-restore` 跳过布局和导图恢复，仍显示最近文件；命令行指定的文件在恢复后打开并激活。
`documents-v1.json` 独立保存最近路径、退出会话及可选页面视图，兼容旧版本1记录；布局文件仍只保存外壳，导图内容保存在版本5 `.mindmap` 文件中。
页面失效时回到主导图，损坏视图仅回退对应页默认视图；恢复不改写导图或历史，不保存编辑草稿，仅保证正常退出时的快照。
大纲和节点属性分别使用 Alt+1、Alt+2，默认仅展开右侧节点属性；Alt+3 打开导图设置侧栏。
大纲标题栏可选择显示所有层或1～9层，根主题计为第1层，首次使用默认显示2层。
大纲层级和展开状态按会话保留，最近选择的层级保存在本机并作为后续新会话默认值；手动展开、收起可继续调整当前视图。
画布选中深层主题不会自动撑开大纲，层级操作不改变导图折叠状态、修改标记或撤销历史。
窗口布局和滚轮偏好只保存在本机，应用配置命名空间为 `mindmap-workbench`；导图结构和主题间距保存在各自导图文件中。
主菜单依次为文件、编辑、视图、设置；滚轮仅从状态栏切换，同步所有标签并在重启后恢复，关闭全部导图时三个状态栏按钮原位禁用。
文档导出菜单及专用接口已删除；“文件 → 导出图形”子菜单提供 PNG 图片、SVG 矢量图、PDF 文档。
选择格式后直接打开对应的保存对话框，并保留折叠范围选择；打开、保存与剪贴板能力保留。
旧会话中的辅助窗口和浮动面板自动迁回主窗口，自动保存及 `Shift+F12` 恢复默认布局继续可用。

布局与文档编解码支持实例级显式注册，打开和保存筛选固定为 `.mindmap`，扩展注册不会扩大文件操作范围。
底层通用文件与内存编解码接口继续保留，JSON、Markdown 和文本仍用于剪贴板交换；工作台使用树形布局，不提供算法选择菜单。
当前文件写入格式为版本 5，兼容读取版本 2 单页、版本 3 子导图和版本 4 详情页文件。打开旧文件不会立即改盘，
显式保存或内容修改后的自动保存使用新格式，并保留已有节点标识、样式和图片。

双击节点可直接编辑文字，仅保留节点的蓝色圆角高亮、光标和文字选区，不显示额外虚线框。
编辑区贴合正文，输入变长时节点与连接线实时调整；达到最大文本宽度后自动换行，
最大宽度沿用节点属性设置。`Shift+Enter` 换行，`Enter` 或 `Tab` 确认，`Esc` 取消并恢复原尺寸。
输入法候选完成前不确认或取消编辑；整次编辑只在提交时产生一条撤销记录。

## 子导图与路径导航

当前页中没有普通子节点的主题可以通过右键“创建子导图”拥有一张独立子导图，
创建后直接进入；仅有根节点的页面也支持继续下钻。子导图中的叶子节点可以继续
创建子导图，不设人为层级上限。入口与子图根节点的名称双向同步，布局和主题从
父页复制后独立调整。已有子导图的入口保持叶子状态，新增子节点、粘贴分支和拖入
节点会提示进入子导图添加内容；双击正文仍编辑文字，右侧常驻页面图标用于进入。

标签栏下方的固定路径栏仅显示页面层级，例如“主导图 › 一级子导图 › 二级子导图”，
省略各页中的普通祖先节点。无选择或选中普通节点都不延长路径，多选时另显示选中
数量；主导图内只显示主导图根节点。页面名称使用纯文字，当前页面高亮，同名页面按
标识分别保留。点击页面可切页并定位其根节点，过长页面链的中间层级收进“…”菜单。
悬停可查看完整页面路径，也可以右键“复制完整路径”，复制内容不包含省略号。

路径栏只保留返回上级按钮与当前页面路径。“↑”按页面归属返回，悬停提示会显示实际去向，
例如“返回主导图”“返回所属想法”或“返回上级导图”；主导图中返回按钮禁用。
返回时恢复离开时的缩放、画布中心、选择和临时导航状态；
再次进入已访问页面也恢复现场。首次进入以 100% 显示并居中根节点。各页缓存保留
在当前打开会话中，正常退出只保存当前页视图供重启恢复，手动关闭标签后重开从主导图开始。输入法候选未完成时保留原页，完成输入
后可继续导航。只读模式允许浏览与跳转，禁用创建、删除和内容编辑。

不再提供手动分支聚焦及退出功能，右键菜单、视图菜单和 `Ctrl+F` 画布绑定均已移除。
`Esc` 用于取消文字编辑、拖动或关闭菜单，空闲时保持当前视图。导航定位折叠节点时
仍可临时显示目标，保留文档原有折叠状态，并随页面视图一起恢复。

整份文件包含全部页面与图片，共用自动保存、修改标记和撤销历史；跨页撤销、重做
自动显示操作所属页。原生复制、剪切、粘贴包含节点拥有的全部子导图，副本使用新的
节点和页面标识。删除子导图保留入口，删除入口或祖先分支时一并删除其下所有页面，
均可一次撤销恢复。大纲、属性、导图设置及 PNG、SVG、PDF 导出只作用于当前页，
路径栏和页面按钮不进入导出。第一版不提供“展开到当前页”。

执行 `uv run --locked --all-packages python scripts/verify_submaps.py` 可验收明暗主题、
普通和紧凑模式以及 100%、150%、200% 三档显示缩放，中文报告和截图写入
`.artifacts/submaps/offscreen/`。

## 子导图收藏

各级子导图可通过路径栏右端的星标收藏、取消收藏，也可以在入口节点的右键菜单中
选择“收藏子导图／取消收藏”。星标始终对应当前页面，节点右键操作对应其拥有的
子导图；主导图和节点详情页不提供收藏。

左侧“收藏”按钮或 `Alt+4` 打开收藏侧栏，首次使用默认收起。列表按最近收藏在前
排列，显示当前页面名称和完整页面层级路径，长文字省略、悬停显示完整内容。
单击或按 Enter 进入页面，恢复该页已有的缩放、位置和选择；当前页高亮，列表右键
可取消收藏。同名页面通过稳定标识分别保留，改名和移动入口后同步更新名称及路径。
只读模式允许浏览和跳转，禁用收藏修改；输入法候选未完成时保留草稿及正式收藏状态。

收藏保存在当前 `.mindmap` 文件的 `metadata.submap_favorites` 中，随版本 5
格式，缺少该字段的旧文件视为空收藏。收藏、取消收藏支持撤销、重做及自动保存；
删除子导图或其祖先分支时同时清理相关收藏，一次撤销恢复页面及原收藏顺序。
另存为或复制完整文件会保留收藏，复制粘贴分支产生的新子导图默认未收藏。
每个文档标签拥有独立列表，侧栏停靠位置、尺寸和展开状态沿用本机布局恢复机制。

## 节点详情页

主导图、子导图中的每个节点都可以通过右键“添加详情页”拥有一张独立的详情导图，
包括根节点、有普通子节点的主题和已有子导图的入口。创建后直接进入，入口与详情根主题
名称双向同步；布局、主题和入口样式在创建时复制，此后外观独立调整。
详情页内可正常编辑、添加、折叠和拖动普通分支，但任何节点都不能再拥有详情页或子导图。
原有子导图的叶子限制继续生效，两类页面可同时属于同一个叶子节点。

详情页入口使用信息圆圈，子导图保留页面图标；同时存在时按详情、子导图顺序常驻显示，
与折叠按钮分别命中。双击正文仍编辑文字。详情路径末项带“ · 详情”，返回所属导图时
恢复缩放、位置及选择；正常退出后重启也能恢复详情页，手动关闭标签后重开从主导图开始。只读模式允许查看已有页面。

全部页面随同一份 `.mindmap` 保存，共用撤销历史和自动保存。复制、剪切及普通粘贴携带
两类页面；粘贴到详情页时若包含附属页面，确认后仅粘贴普通分支、文字、图片和样式，
附属页面不展开到当前页，也不改写剪贴板；取消不改变目标。删除详情保留入口与子导图，
删除子导图保留入口自身的详情，删除入口或祖先分支时连带删除其拥有的全部页面，均可撤销。
大纲、属性、导图设置及图形导出只作用于当前页，页面图标与导航栏不进入导出。

`scripts/verify_submaps.py` 同时验收两类页面，在明暗主题、普通和紧凑模式及三档缩放下
生成入口、详情页截图与中文报告，输出仍位于 `.artifacts/submaps/`。

## 灵感侧栏与独立想法

每份导图文件保存各自的独立想法，通过左侧“灵感”面板选择并编辑。
列表可以为空，点击灵感标题栏右侧的“＋”或双击想法画布空白处即可创建主题；
加号与选项、隐藏按钮一起显隐，遵循面板悬停、活动状态及“始终显示标题图标”设置。
加号悬停提示“新建想法”，空列表额外显示“新建想法”文字按钮；搜索框紧跟标题栏。
已有想法但搜索无匹配时仅显示无结果提示，空画布保留新建操作的提示。
主题可继续添加子节点、详情页、图片及符合既有规则的子导图，全部内容随同一份文件保存。

采用“灵感侧栏＋单个想法画布”。侧栏每项代表一棵游离树，可搜索标题，
显示普通子主题数量；单击后只编辑这一棵树，并分别记住缩放、位置和选择。
侧栏只支持单选，不提供批量整理、排序或共同父主题入口。按下或拖起列表项不切换画布。
右键想法仅提供“加入导图…”和“删除想法”，两项之间使用分隔线，不设置默认动作。
操作始终对应右键命中的想法；弹出或取消菜单
不切换画布，也不改变原来的列表选择。空白处右键提供“新建想法”，面板布局选项仍从标题栏进入。
单击列表或按 Enter 打开想法，文字在画布中编辑。
只读及输入法候选期间禁用修改项；迁入和删除复用画布既有确认、撤销及自动保存逻辑。
“灵感”与大纲、收藏共用左侧停靠区域，也可通过 Alt+6 打开；切回主导图后保持打开，允许手动收起。

从侧栏将想法拖到当前想法、主导图或子导图时，与画布内节点拖动共用落点和预览：
节点正文接为最后一个子主题，正文外缘和同级间隙按提示插到前后；向下布局对应左右插入，
双向布局支持左右分支落点。使用相同的半透明分支影像、圆角目标高亮、虚线预连接、
插入短条和文字气泡，并按24／36逻辑像素进入、退出吸附，靠近画布边缘自动滚动。
悬停不移动其他节点或展开折叠目标；成功放下后才展开并以140毫秒重排，超过500个可见节点直接显示结果。
迁入保留节点自身样式、全部后代和附属内容，继续使用目标页的布局和主题；不向详情页或其他文件拖入。
把画布分支拖回侧栏，则成为独立想法，画布留在原处继续整理。
侧栏想法拖到画布空白处不组合；单想法画布内部的空白落点不拆分。
Esc 取消拖动，成功放下只产生一次撤销记录；只读和输入法候选期间禁止修改。
侧栏底部平时不显示拖拽提示框或保留占位，合法分支拖入时才显示松手提示；
离开或取消时隐藏，成功拆出后显示新增数量并在1.6秒后隐藏，连续拖放不会被旧倒计时打断。

画布每次只展示一个想法，根节点在展示原点，树内自动布局；双击空白处新建并打开另一条想法。
画布现有多选与“创建共同父主题”保留，重叠选择只处理最上层分支。

主导图及各级子导图中的普通分支可通过右键或编辑菜单“转为独立想法”整条移出。
在想法画布选择分支后，使用“加入导图…”选择目标页面和父主题，分支追加为其最后
一个子主题。目标选择器支持查找并显示完整路径；各页面自身的根节点保持保护，
详情页内部不提供跨区移动入口。菜单迁移和侧栏拖放共用同一份完整内容与历史。

迁移保留节点与页面标识、全部普通后代、详情页、各级子导图、图片、备注、链接、
样式、折叠状态和子导图收藏关系。节点不能移入自身、后代或其拥有的附属页面。
旧文件保存的游离根坐标继续保留，新根沿用右侧80个逻辑像素间距的兼容落位规则；
这些存储坐标不影响单个想法画布的显示位置。

内容和根坐标共用现有500毫秒防抖自动保存及撤销重做；跨区撤销显示操作前位置，
重做显示操作后位置。正常退出可恢复单个想法及其附属页面，已访问想法的视口保存在本机配置中。
旧总览会话恢复为最近有效想法或首项，忽略总览视口，已有单想法视口继续保留。
无选择时粘贴文字或分支会创建游离树，粘贴图片仍需先选择父主题。
大纲与图形导出只包含当前想法，导出标题使用根主题名称；空态禁止导出。

原生格式继续使用版本5的独立区域记录，旧版本2、3、4读取为空想法列表，浏览不会改盘。
运行 `uv run --locked --all-packages python scripts/verify_inspiration.py` 可生成明暗主题、
普通与紧凑模式及100%、150%、200%显示缩放的中文验收报告和截图。
运行 `uv run --locked --all-packages python scripts/verify_branch_transfer_drag.py` 可验收原生拖入的
四种布局、明暗、普通与紧凑和三档显示缩放，共48组界面配置，另检查千节点连续拖动不重复测量或布局。
中文报告和截图写入 `.artifacts/branch-transfer-drag/`。

## 工作区

十个成员按引擎、Qt 组件、桌面基础设施和应用分组，分别独立构建，共用根目录的 `.venv` 和 `uv.lock`。

```text
packages/
├─ engine/
│  ├─ mindmap-core/
│  ├─ mindmap-layouts/
│  └─ mindmap-formats/
├─ qt/
│  ├─ mindmap-qt-render/
│  ├─ mindmap-qt-ui/
│  ├─ mindmap-qt-canvas/
│  └─ mindmap-qt-panels/
└─ desktop/
   ├─ mindmap-docking/
   └─ mindmap-shell/
apps/
└─ mindmap-workbench/
tests/
└─ integration/
```

| 成员 | 职责与依赖边界 |
| --- | --- |
| mindmap-core | 模型、编辑、事务、历史、事件及扩展协议，仅依赖标准库 |
| mindmap-layouts | 树布局、连接线路由、增量几何，只依赖核心 |
| mindmap-formats | 原生容器、JSON、大纲、剪贴板解析及原子读写，只依赖核心 |
| mindmap-qt-render | 文字图片测量、静态绘制及图形导出，只依赖核心和 Qt |
| mindmap-qt-ui | 共享控件、表单、弹窗及色板，分支预览复用布局与渲染 |
| mindmap-qt-canvas | 交互编辑、选择、拖动、剪贴板及文件控制器 |
| mindmap-qt-panels | 通过公开宿主协议连接的大纲、属性和全局设置，不依赖画布 |
| mindmap-docking | 停靠、文档标签、分屏、主题与布局持久化，仅依赖 Qt |
| mindmap-shell | 主窗口、应用动作、菜单、启动与项目模板，依赖停靠和 Qt |
| mindmap-workbench | 多导图会话、自动保存及应用装配，组合上述组件 |

分发名中的连字符对应导入名中的下划线，例如 `mindmap-core` 使用 `import mindmap_core`。
调用方直接导入能力提供者：模型及编辑来自 `mindmap_core`，默认布局来自 `mindmap_layouts`，文件读写来自 `mindmap_formats`。
每个成员的单元与组件测试位于自身 `tests/`；跨包组合、依赖边界和发行回归位于 `tests/integration/`。
根 pytest 按成员目录收集，新增测试无需逐项修改根配置。
依赖边界检查递归扫描运行子目录，同时拒绝跨包私有模块和私有符号导入；独立项目
模板按其自身元数据验收。增量布局、后台编码的能力判断分别由布局包、格式包提供，
工作台通过组件公开接口管理输入法状态、弹层和界面色板。
