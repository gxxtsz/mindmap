# mindmap-qt

基于 PySide6 的原生思维导图组件，依赖 `mindmap-engine`，不依赖桌面外壳或停靠框架。
独立包要求 Python 3.12+、PySide6 `>=6.9,<7`；当前工作区与工作台共同使用 PySide6 6.12.0 验收。

```python
from PySide6.QtWidgets import QApplication
from mindmap_engine import MindMapEngine
from mindmap_qt import MindMapWidget

app = QApplication([])
widget = MindMapWidget(MindMapEngine())
widget.resize(1100, 750)
widget.show()
try:
    app.exec()
finally:
    # 宿主退出时主动释放引擎订阅及未完成下载。
    widget.dispose()
```

组件提供节点、图片和 11 种父子分支的绘制及 PNG/SVG/PDF 导出。
专用剪贴板使用当前版本 JSON，与原生容器共用文档结构校验，不读取旧版本数据。

构造函数接受 `layout_registry` 和 `format_registry`，省略时分别创建独立默认实例。
画布与图形导出使用同一个布局注册表，剪贴板使用注入的 JSON、Markdown 和纯文本实现。
自定义格式注册表需保留这三个标识才能使用完整剪贴板能力。
亿图普通脑图的粘贴直接识别 `application/edraw-mind-xml`，支持 XML 及批量复制的本机
`copy.xml` 路径载荷，不需要为文件注册表增加格式。识别顺序为项目专用 JSON、亿图、现有文本；
亿图数据损坏或临时文件失效会报错，请重新复制，不会降级为纯文本。
每次有效的亿图粘贴均询问追加或替换；替换适用于中心及普通节点，可选择保留原后代，保留的后代排在新后代之前。
粘贴方式以整行卡片呈现，选中时同时显示强调色背景、粗边框和“已选择”标签。
仅在替换模式下显示“保留原有后代／移除原有后代”文字按钮；主操作对应显示“追加粘贴／替换粘贴”。
多个来源根只允许追加。替换保持目标标识、位置和既有属性，仅替换正文与所选后代；新增主题使用项目默认外观并继承目标分支配置。
来源样式、图片、备注和链接不导入，成功后一次撤销／重做覆盖全部更新和选择；取消不改变文档或偏好。

`widget.edraw_paste_options` 返回 `(mode, keep_children)`，初始为 `("append", True)`。
使用 `set_edraw_paste_options("append" / "replace", bool)` 恢复默认选择，并监听
`edraw_paste_options_changed(str, bool)` 保存成功后的实际变化；偏好不属于导图或历史。
组件只在内存保存偏好，工作台通过其 `preferences.ini` 跨重启保存两项选择。
多根来源暂时限制为追加，不会覆盖之前的单树粘贴方式；每次仍显示弹窗。
通过 `widget.set_layout(config)` 切换布局，会在提交历史前校验并试算；加载新文档前可调用
`widget.validate_document(document)`，确认算法、图片和几何结果有效后再替换引擎文档。

宿主负责 QApplication 生命周期。组件支持多实例、只读模式、事件信号和菜单扩展。
内置工具栏使用 SVG 图标，悬停显示中文功能名称和当前快捷键，支持明暗主题及高 DPI 显示。
图标按钮复用原有动作，菜单名称、快捷键和只读限制保持一致。
默认工具栏提供撤销、重做、适应窗口和回到中心；“添加子节点”可通过右键菜单或 Tab 快捷键调用，
宿主仍可复用 `widget.action("add_child")` 或调用 `widget.add_child()`。
宿主若希望将历史操作融入自己的标题栏，可构造 `MindMapWidget(toolbar=False, view_controls=True)`，
隐藏传统工具栏并在视口右下角显示适应窗口、回到中心。浮条随视口尺寸自动定位，复用原动作并跟随界面色板，
不增加场景元素，不改变导图主题或图形导出；默认关闭，独立组件原有布局保持不变。
宿主已提供标签栏和外层圆角时，可传入 `embedded=True`，移除画布内部圆角及8像素内边距。
该模式使用界面色板的 `field` 作为屏幕画布底色，配合 `set_ui_colors()` 跟随宿主明暗主题；
导图主题、撤销历史和导出背景保持原值。默认 `embedded=False` 保留独立组件的圆角与文档背景。
节点属性可从右键菜单或 Alt+Enter 打开；宿主也可接管该入口并显示属性侧栏。
分支连接线选择位于节点属性的“分支”分组。
按住右键拖动可平移画布，右键单击保留菜单，中键或 Alt+左键也可平移。
画布始终隐藏横向与纵向滚动条，内容增加时自动扩展，删除、折叠或聚焦后按当前
可见内容重新计算并收缩。四周各保留一屏操作余量，随窗口大小和缩放比例换算；
拖动或滚轮到达边缘后停止移动，不会继续扩展空白区域。自动调整保持缩放比例和
有效范围内的视口中心，中心越界时移到最近边界。
“适应窗口”按内容范围计算，“回到中心”定位根节点或当前聚焦节点；缩放动作围绕
视口中心进行，滚轮缩放在有效范围内保持鼠标锚点。导航余量不计入图片或文档导出。
右上角导图设置菜单切换滚轮上下滚动或缩放，默认上下滚动；Ctrl+滚轮始终围绕鼠标缩放。
独立画布保留 `widget.action("wheel_mode")` 及其图标菜单，宿主可加入自己的菜单或工具栏。
用 `wheel_mode` 查询模式、`set_wheel_mode("scroll" / "zoom")` 设置模式，并通过
`wheel_mode_changed(str)` 监听实际变化。模式独立于文档和撤销历史，只读时也可切换；
持久化由宿主管理，组件自身不读写本机偏好。

节点属性单页中的“分支”分组通过图标下拉入口打开四列十一项圆角网格，提供中文提示、当前项高亮及恢复原始曲线。
节点属性及属性弹窗共用约 268×230 逻辑像素的紧凑弹层，保留右侧对齐、阴影和屏幕边缘避让。
支持整个子树或仅本级，悬停显示提示，关闭菜单不修改样式。
侧栏点击后自动提交；弹窗按“确定”与外观一起提交一次历史，取消不修改文档；未改样式不覆盖后代。
`widget.set_branch_style("round", scope="subtree")` 使用当前选择，无选择时使用聚焦主题或根主题；
`scope="level"` 仅改本级，`None` 恢复默认。只读、文字编辑和不支持此能力的布局禁用入口。
画布、选择器和导出复用正式路由与描画，旧 `Curve` 布局扩展保持兼容。
`widget.action("properties")` 和 `widget.action("branch_style")` 继续可供宿主复用；后者保留四列菜单和临时预览能力。
在工作区运行 `uv build --package mindmap-qt` 构建独立安装包。

## 独立 Qt 停靠工作区

使用 `from mindmap_qt import MindMapWorkspace` 创建包含原画布、完整大纲、节点属性及全局设置的工作区，
其构造参数与画布一致，原画布可以通过 `workspace.canvas` 访问。
工作区可嵌入普通 Qt 布局，也可作为 `QMainWindow` 的中央控件；无需新增界面依赖。
桌面工作台通过下文的 `MindMapPanels` 接入项目内置外壳，由 `mindmap-shell` 和 `mindmap-docking` 管理桌面布局。

工作区采用卡片分区：浅色外围为 `#E9EAEE`、两个侧栏为 `#F5F6F8`，深色外围为 `#1E1F22`、侧栏为 `#2B2D30`。
大纲和节点属性的标题、内容、滚动区空白及底部圆角留白使用同一底色，左侧、右侧、底部停靠和浮动状态保持一致。
输入框保留浅色白底及深色 `#303237`；独立属性弹窗与菜单沿用原有底色。样式原地刷新，保留焦点、光标、滚动和未提交输入。
卡片圆角 8、间隙 6、按钮栏 40、标题栏 36，均为逻辑像素；界面沿用当前文档的文字色和强调色。
内部 `ui_style` 统一配色、控件及菜单样式，
只作用于组件自身，不修改 QApplication 或宿主的全局样式。文件和颜色选择对话框仍由宿主与 Qt 管理。
中央画布卡片仍使用 `Theme.background`，节点和导出继续读取原文档主题；卡片边角、外围及间隙不参与导出。
独立 `MindMapWidget` 同样使用圆角画布承载层，原 `view`、`scene` 和动作接口不变。

侧边按钮支持左、右、底部停靠、同侧排序及拖出浮动；关闭浮动窗口只隐藏面板。
默认右侧展开节点属性，大纲隐藏；导图设置通过右上角菜单访问。每个区域同时展示一个面板，不同区域可以同时展开。
大纲树使用 16 逻辑像素缩进、28 行高和 12 像素正文，使用实心三角、灰色叶节点圆点及连续的祖先竖线。
大纲树区沿用所有侧栏共用的底色，保持连续的卡片表面。
选中态沿用主题的柔和强调色，内置浅色和深色分别为 `#DFE9F8`、`#374251`；文字、三角和叶节点随工作区配色。
大纲支持像素滚动、原生键盘展开及多选定位，树自身的展开与收起不改写画布折叠状态。
大纲标题栏提供层级下拉按钮，支持“显示所有层”和“显示1层”至“显示9层”。
入口使用与标题栏工具统一的低对比度线条图标，悬停提示当前层级，菜单勾选保留上次应用的预设。
桌面工作台中，该入口与标题栏的选项、隐藏按钮共用显隐规则；独立工作区沿用自身标题栏按钮的显示方式。
根主题计为第1层，默认显示2层；“所有层”可以展开超过9层的导图。重复选择同一选项会重新应用预设。
菜单勾选表示上次应用的层级；之后仍可手动展开、收起分支，画布选中隐藏节点不会自动展开大纲。
正文、主题刷新及结构编辑保留已有分支状态，新分支按所选层级初始化；整份文档替换时重新应用预设。
`workspace.outline` 或 `panels.outline` 提供 `display_depth: int | None`、
`set_display_depth(depth)` 和 `display_depth_changed(object)`，其中 `None` 表示所有层，整数范围为1～9。
非法值抛出 `ValueError` 且不修改状态；重复设置会重新应用，但只有预设变化时才发出信号。
标题栏通过 `depth_action` 复用面板持有的动作和菜单；只读时也可使用，不影响导图、修改标记及撤销历史。
独立组件不访问本机配置，宿主可监听信号保存预设，并在启动时调用设置接口恢复；手动调整的分支状态不持久化。
定位被折叠隐藏的主题时，会在一次事务中展开所需祖先；只读模式拒绝需要展开文档的定位。
节点属性共享独立画布的单页表单，按字体、主题、分支分组，支持字体搜索、字号增减、色块选择和自定义最大文本宽度。
没有 Tab 或内容编辑字段，已有正文、备注、标签等数据完整保留；正文继续在画布中原地编辑。
节点属性侧栏自动提交：离散选项立即提交，字体名称和数值等待 400 毫秒或失焦后提交，
多选只更新实际修改的样式及分支字段。

`show_tool_window("outline" / "properties", focus=True)` 展开面板，`hide_tool_window(...)` 隐藏，
`restore_state(None)` 恢复默认布局。`save_state()` 返回普通字典，宿主监听 `state_changed`
并自行保存本机偏好；组件不访问 QSettings。保存或导出图形前调用 `flush_pending_edits()`。
直接调用 `workspace.canvas.export(...)` 也会先通知侧栏提交有效输入。
该画布接口导出正式文档，不提交原地文字草稿；需要包含草稿时，宿主应先调用
`workspace.canvas.finish_edit(commit=True)`。文件控制器会统一完成这一步。
宿主永久移除工作区时调用 `dispose()` 取消未完成输入、拖动和网络请求；临时隐藏面板时保留实例。

`MindMapWidget.set_properties_handler(handler)` 可由宿主接管属性入口，传入 `None` 恢复弹窗。
独立画布仍可使用属性弹窗，应用菜单与文件操作由宿主提供。

## 全局设置

独立 Qt 工作区及桌面工作台均通过右上角“设置 → 导图设置”或 Alt+3 打开菜单，
不再提供设置侧栏、侧边齿轮或设置工具窗口。独立工作区的 `toolbar=False` 不会隐藏设置入口。
菜单提供滚轮行为、布局方向、紧凑布局、连接线样式和导图主题，单选项显示当前勾选状态。
当前选项固定使用蓝色底、粗体文字、左侧标记和右侧勾选，鼠标悬停或键盘定位其他选项使用中性灰底。
选中状态在移开鼠标后保留，浅色和深色界面分别使用适配的蓝色与灰色；左侧功能图标保持独立。
上级菜单直接显示“布局方向：向右”等当前值，紧凑布局显示已启用或未启用，混合分支及自定义主题也显示对应摘要。
桌面原有界面外观与布局选项仍保留在同一齿轮菜单中，导图主题与界面主题独立。
`workspace.show_settings_menu()` 可直接展开菜单；查看菜单不会切换侧栏或主动结束文字编辑。
`workspace.settings`、`panels.settings` 保留兼容表单对象及原有设置能力，但不再注册为停靠窗口。
宿主可调用 `panels.settings.create_menu(parent=None) -> QMenu` 创建共用菜单，加入自己的设置入口。
菜单由指定父控件拥有，省略父对象时由设置对象拥有；宿主退出前调用 `panels.dispose()` 关闭全部菜单。
原 `show_tool_window("settings")`、`hide_tool_window("settings")` 等调用按未知工具处理；
恢复旧布局时忽略设置侧栏记录，其余面板布局继续恢复。
布局方向、紧凑布局、分支和主题从当前导图读取，修改后支持撤销、重做及保存重开。
主题支持浅色和深色；已有自定义主题显示“自定义”，打开或刷新菜单不会替换它。

新建导图默认选中圆角正交，新建及后续新增主题沿用该样式；已有文件按保存的样式打开。
全局分支选择在菜单中列出原始曲线及全部连接线样式，始终覆盖整张导图，包括折叠、聚焦范围外及叶节点，
不受当前选择和局部作用范围影响；恢复原始曲线也作用于整图。新增子节点、同级节点及父节点沿用现有继承规则。
局部分支设置继续保留，出现差异时全局入口显示“多种样式”，再次选择全局样式可统一。
移动和项目内部粘贴保留节点原有配置；亿图仅粘贴树形数据，新节点沿用目标的分支配置。
一次全局修改只产生一条撤销记录，其他节点属性保持原值。

提交文档设置前先保存节点属性中的有效待提交输入，并验证完整候选文档；失败后恢复控件显示并通过错误信号报告。
只读或文字编辑期间禁用文档设置，滚轮仍可调整；不支持的布局能力单独禁用并提供中文提示。
`MindMapWorkspace.save_state()` 返回版本 1 的布局字典。
该版本只描述独立 Qt 工作区布局，与导图文件版本 2、桌面会话布局分别管理。


## 独立宿主集成

`MindMapPanels(canvas, parent=None)` 为一个画布提供 `outline`、`properties`、`settings`
业务对象；大纲和属性放入布局或停靠容器，设置通过 `settings.create_menu(parent)` 加入宿主菜单。
组合负责大纲定位、选择同步和属性提交，使用 `flush_pending_edits()` 提交有效属性输入。
退出宿主时先调用 `panels.dispose()`，再调用 `canvas.dispose()`；
二者均可重复调用。面板组合的清理不销毁 QWidget，控件归属和最终销毁由宿主负责。

`MindMapFileController(canvas, panels, dialog_parent=None, *, writer=...)`
提供宿主无关的文件生命周期，不读写本机偏好，也不拥有画布。
`path` 表示当前保存位置，`is_dirty` 只反映引擎修改状态；有损文件导入及其待保存状态已删除。
`new_document()`、`open_path()`、`save()` 返回是否完成操作，
`confirm_replace()` 统一处理保存确认；主文档只使用可完整往返的格式。
`open_path(path)` 仅接收 `.mindmap`，不再接受 `format_id` 参数；扩展名比较忽略大小写，始终使用原生容器解码。
`validate_open_path(path)` 在读取文件、分配会话和提交输入前校验扩展名；不匹配时抛出 `MindMapError`。
`open_dialog()` 只显示 `思维导图 (*.mindmap)`，取消或校验失败不改变当前文档；JSON、大纲及扩展格式不能用于文件打开。
保存、图形导出和确认替换前，控制器会提交有效属性输入与原地文字。
`save_committed()` 仅将已提交快照按当前路径和格式原子保存，返回是否成功；不弹出对话框、不提交侧栏草稿、不结束原地编辑。
该接口用于宿主自动保存，无绑定路径时报告失败；与普通保存共用格式校验和可注入写入器，成功才更新保存标记。
保存事件只更新状态，不触发画布的文档替换通知，不取消菜单、连接线预览或输入法，也不清空撤销历史。
多导图宿主应为每份会话分别创建画布、面板组合和文件控制器，自行管理活动会话、文件归属、计时器及关闭策略。
文件解析和画布验证成功后才询问是否替换；写入成功后才更新路径与保存标记。
`export_dialog(format_id="svg")` 接受 `png`、`svg`、`pdf`，打开所选格式的保存对话框及折叠范围选择，默认使用 SVG。
默认文件名和唯一文件筛选对应所选格式；省略扩展名时自动补齐，其他扩展名或无效格式抛出 `MindMapError`。
取消文件选择时不询问导出范围，成功导出不更新保存位置，也不清除未保存标记。
文档导出专用的 `export_document_dialog()`、`export_path()` 已删除，不保留兼容接口。
`format_filters()` 仅接受 `open`、`save`；`open` 固定返回原生格式筛选，`save` 根据完整往返能力生成；其他值抛出 `MindMapError`。
格式注册表、编解码器与原子写入继续用于正常保存和剪贴板，JSON 保存保持可用。
`open_path()` 的异常交给宿主处理；
`save()` 写入失败返回 False，并通过 `error_occurred(str)` 报告。
`state_changed` 通知文件状态变化，`message(str)` 提供导出结果提示。

`MindMapWidget.set_ui_colors(colors)` 与
`MindMapPanels.set_ui_colors(colors)` 接受 `UiColors` 或 None，可覆盖界面控件和菜单色板，
不改变导图主题、撤销历史或图形导出；传入 None 恢复默认的文档主题派生配色。
独立 Qt 工作区上文列出的色值属于默认配色，桌面工作台会按外壳主题映射界面色板。
公共接口的完整签名及生命周期说明见[面板组合](src/mindmap_qt/panels.py)、
[文件控制器](src/mindmap_qt/files.py)；框架接入示例见
[桌面适配层](../../apps/mindmap-workbench/src/mindmap_workbench/shell_adapter.py)。
