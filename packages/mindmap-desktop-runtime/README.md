# 导图桌面运行时

`mindmap-desktop-runtime` 实现窗口、标签、分屏、命令路由、会话、设置和操作日志。Python 导入名为 `mindmap_desktop_runtime`。业务模型与导图文件编解码属于导图应用层。

## 装配与生命周期

产品使用 `DesktopConfig` 声明窗口信息，必须传入 `application_factory` 构造唯一的导图应用。窗口直接通过应用的新建和打开接口处理 `.mindmap`；欢迎页、文件菜单和拖入入口遵守同一限制。

核心应用初始化失败时释放已登记资源并抛出错误。正常关闭先完成所有共享文档的保存检查，再原子提交会话，最后释放应用与界面资源。

`run_desktop()` 处理启动参数和 Qt 事件循环。产品实现见[应用入口](../../apps/mindmap-app/src/mindmap_app/app.py)。

## 会话与配置

- `mindmap-state-v2.json` 以同一快照保存标签、活动导图、最近文件、页面状态、分屏及窗口位置。
- 视图记录仅包含 `id`、`document_id`、`path`、`view_state`；导图本机状态使用 `mindmap` 字段。
- `mindmap-settings-v1.json` 保存窗口和导图偏好。
- 启动期间设置保存屏障，避免后台打开大文件时写入不完整现场。配置损坏时保留备份，无法备份则禁止覆盖。
- 运行时只解释当前格式。历史配置的文件名、字段和业务归档统一由产品[迁移层](../../apps/mindmap-app/src/mindmap_app/migration.py)转换。

## 桌面行为

面板使用统一停靠和分屏机制；临时暂停面板保留其布局偏好。活动标签、输入框和节点页面共享编辑快捷键路由。动态菜单、标准动作和临时控件有明确的生命周期。

窗口恢复保留显示器、普通位置、尺寸、最大化与全屏状态。显示器断开后使用当前屏幕的可用区域。资源文件通过清单校验原始字节，检出和打包统一保留 LF。

内部协议见[桌面 API](../mindmap-desktop-api/README.md)，扩展接入见[节点页面协议](../../docs/架构与节点扩展.md)。
