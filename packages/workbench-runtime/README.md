# 工作台运行时

`workbench-runtime` 是基于 PySide6 的通用桌面宿主，Python 导入名为 `workbench_runtime`。运行时实现宿主服务，编辑器和文件格式由插件提供。参见[工作台插件接口](../workbench-api/README.md)。

## 主要职责

- 提供主窗口、文档标签、分屏、停靠面板和主题。
- 按依赖顺序激活插件，管理命令、面板等扩展。插件激活失败时撤销其已完成的注册，退出时释放插件资源。
- 协调文档的打开、保存和关闭，管理最近文件、操作日志和会话。恢复会话时，运行时根据保存的路径和视图状态重新打开文档，由编辑器插件读取文件内容。

## 标签、分屏与工作现场

- 点击标签会激活其分屏。活动组用强调色标记，新建和首次打开的文档进入该组。已有文件在原位置激活。
- 同名文件显示能区分的最短目录后缀，悬停可查看完整路径。标签右键菜单可以移动标签到新分屏，也可以请编辑器在新分屏打开同一文档的独立视图。
- 运行期间合并连续的标签、布局和视图变化，将完整工作现场原子保存到 `workbench-state-v1.json`。启动恢复完成前暂缓保存，防止后台读取文件时提交中间状态。首次读取仍兼容旧的单独布局文件。

## 主菜单

- 「文件」菜单按已注册的编辑器生成新建入口。只有一种类型时直接显示「新建」加类型名，多种类型时从「新建」子菜单选择。`Ctrl+N` 优先使用活动编辑器，无活动编辑器时使用首个已注册类型。
- 「编辑」菜单在固定位置提供六个标准动作，按焦点将操作交给文本输入框或活动编辑器。
- 「视图 → 面板」列出当前可用的停靠面板，勾选状态对应面板的布局显隐。「设置」集中管理工作台主题、布局和插件启用状态。
- 插件按稳定位置注册业务动作。动态菜单回调失败时，工作台记录错误并继续装配其余菜单项。

## 宿主入口

从 `workbench_runtime` 导入 `WorkbenchConfig`、`WorkbenchRuntimeWindow` 和 `run_desktop`。配置对象设置应用标识、标题和图标，窗口类负责装配宿主。`run_desktop(builder, ...)` 解析启动参数，将参数交给窗口工厂 `builder`，并运行 Qt 事件循环。参见[个人工作台的装配实现](../../apps/personal-workbench/src/personal_workbench/app.py)。

构造窗口时，可用 `storage_dir` 指定状态、布局和设置的存储目录。传入 `restore=False` 时以默认布局启动，仍读取设置和最近文件。

产品可传入 `profile_upgrade(state, settings)` 处理已加载的配置。回调在插件激活和会话恢复前原地修改状态及设置值字典，并依次返回状态和设置的布尔变更标记。加载校验通过且已存在的文件在变更后立即原子写回。传入 `restore=False` 时也会执行回调。

## 插件接入 API

省略 `manifests` 时，运行时从 `personal_workbench.plugins` 入口点组发现插件。传入清单列表可指定候选插件，传入空列表可单独启动桌面宿主。运行时根据设置启用插件，校验协议版本，并为每个激活的插件提供独立的 `PluginContext`。

可参考思维导图插件的[入口声明](../../plugins/workbench-plugin-mindmap/workbench-adapter/pyproject.toml)和[清单实现](../../plugins/workbench-plugin-mindmap/workbench-adapter/src/workbench_plugin_mindmap/__init__.py)。
