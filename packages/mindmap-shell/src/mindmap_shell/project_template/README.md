# 我的桌面应用

本项目由 `mindmap-shell` 模板生成，采用独立的依赖与业务包。

```powershell
uv sync
uv run my-desktop-app
```

在 `src/my_desktop_app/app.py` 修改应用配置、内容工厂和动作即可接入业务。
生成器配置了源码路径时，保留本机框架源码目录即可运行；分发时可改为 wheel、
Git 固定版本或正式包版本依赖。当前框架交付尚未上传公开包索引。

示例提供导航、日志与可取消关闭的文本页。“标记已处理”只演示修改状态，
真实应用需要实现自己的文件保存。原创代码采用 MIT，Qt/PySide6 依赖保留原许可。
