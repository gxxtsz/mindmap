# mindmap-qt-canvas

可独立嵌入的 Qt 思维导图交互画布与文件控制器。本包可以独立构建和安装，不依赖桌面外壳或停靠框架。

要求 Python 3.12+、PySide6 `>=6.9,<7`。宿主先创建 `QApplication`，所有图形接口在 GUI 线程调用。

在仓库根目录执行 `uv build --package mindmap-qt-canvas` 构建本包；安装 wheel 时由元数据解析依赖。

## 嵌入画布

```python
from PySide6.QtWidgets import QApplication
from mindmap_qt_canvas import MindMapWidget

app = QApplication([])
canvas = MindMapWidget()
canvas.resize(1000, 700)
canvas.show()
try:
    app.exec()
finally:
    canvas.dispose()
```

`MindMapWidget` 支持独立引擎、多实例、
只读、增量布局、视口虚拟化、原地编辑、拖动、剪贴板、图片导入及图形导出。
宿主负责应用事件循环和清理，组件不保存本机偏好。

面板可以通过 `document_view`、`parent_index`、`is_editing`、`branch_scope`、
`branch_kinds()`、`reveal_nodes()` 等公开接口集成。借用文档禁止修改，查询不会
复制整图；候选编辑应另取引擎快照并调用 `validate_document()`。

`MindMapFileController(canvas, panels, dialog_parent=None, *, writer=..., state=None)` 兼容原调用。
第二参数仅要求提供 `flush_pending_edits()`，无侧栏时可以为空实现，不要求安装面板包。
多个同引擎控制器可传入同一个 `MindMapFileState` 共享路径；省略时仍各自独立。
`prepare_save` 可设置为无参布尔回调，显式保存前由宿主统一检查并提交关联视图输入；返回 False 取消，自动保存不调用。
共享状态只管理路径，宿主负责合并保存调度和成功、失败通知；写入成功才更新共享路径。
共享引擎的宿主将关联画布的 `shared_views` 设为 True，使其他视图的提交只更新内容，保留各自有效页面、选择和视口。
`interaction_id` 是画布的稳定来源标识，直接引擎提交可通过 `engine.event_source(canvas.interaction_id)` 标记；内置画布、面板和异步图片提交已处理来源。
`is_external_event(event)` 判断其他视图或无来源的外部内容通知；独立模式默认 False，保持原有单画布行为。
退出宿主前调用 `dispose()` 解除引擎订阅并取消未完成下载；该方法可重复调用。
折叠按钮由 Qt 的父图元关系管理，只通过弱引用借用所属节点；删除、折叠或替换导图时，
移出场景的节点可立即释放，不依赖循环垃圾回收，也不会被外部保留的按钮包装对象拖延销毁。

## 交互与嵌入接口

组件提供节点、图片和 11 种父子分支的绘制及 PNG/SVG/PDF 导出。
专用剪贴板使用版本5 JSON，与原生容器共用文档结构校验，兼容版本2、3、4数据。

## 独立想法

通过灵感侧栏选择或新建想法；顶部只保留返回上级和当前路径。
返回按钮按实际目标提示“返回主导图”“返回所属想法”等，主导图中禁用返回；
新建按钮集中在侧栏，空想法画布保留操作指引和双击新建。
`show_inspiration(root_id=None)` 恢复指定或最近想法的独立视图，只导航，不产生内容历史。
`current_inspiration_root_id` 在有效想法画布返回根标识，其他页面和空态返回 None。
单想法读模型保留内部区域身份，展示根归零，不改文档保存的兼容坐标。
面包屑直接显示想法名称及其附属页面路径，不显示内部区域项。
`add_inspiration(position=None)` 新建并编辑主题；
`move_selected_to_inspiration()` 整条移出，`attach_selected_inspirations()` 选择父主题接入，
`group_selected_inspirations()` 新建共同父主题。所有入口检查只读与输入法状态。
想法画布内的空白落点不拆分、不自由摆放根节点；Esc 取消，有效结构落点松手一次提交。
跨区提交重载当前页成员读模型，随行但未改字段的子孙不会残留在旧画布或大纲中。

跨控件拖放使用 `create_branch_drag(node_ids=None, origin="canvas")` 生成本文件标识载荷，
侧栏单根来源使用 `origin="sidebar"`；`can_detach_branch_drag()` 只读验收，
`detach_branch_drag()` 在一次事务中拆出分支并留在原画布，成功发出 `inspirations_detached(list)`。
`can_receive_branch_drag(mime, parent_id=None)` 检查当前目标资格，
`receive_branch_drag(mime, parent_id, *, index=None, direction=None)` 独立试算后迁入目标父主题，
`index` 是移除移动根后的子节点插入下标，省略时追加；`direction` 可指定双向根节点的左右分支。
两个关键字均省略时保留原有追加行为，非法位置或方向抛出中文 `MindMapError`；
有效操作的迁入、排序、方向与展开作为一条事务提交，保持目标画布并选中迁入分支。
原生拖入与内部鼠标拖动共用控制器、落点解析器和影像图层：正文接为子主题、外缘及同级间隙插入，
支持双向根节点左右落点和向下布局的左右插入；子导图入口正文拒绝接入，但可作为同级参照。
共用24／36逻辑像素吸附、半透明源影像、圆角高亮、预连接、插入短条、文字气泡和边缘滚动。
源影像进入时建立并缓存，仅绘制当前视口可见的节点和连线，悬停不改文档或重算布局；
成功放下才展开目标并播放140毫秒重排，
超过500个可见节点直接显示最终布局。未提交的预览与已提交的动画分别清理，原生拖放结束通知不提前停止动画。
节点自身样式及附属内容保持，显示使用目标页布局和主题；详情页和跨文件拖入继续拒绝，空白无有效落点不提交。
所有接口均检查会话、文档代次、修订号、只读、输入法及页面归属；无效载荷不提交，
正式异常由宿主通过 `call()` 统一提示。`inspiration_sidebar_requested` 请求宿主打开侧栏。
面板只通过这些公开接口连接，不导入画布私有对象。

双击正文进入无边框原地编辑，保留节点蓝色圆角高亮、输入光标和文字选择，不绘制 Qt 默认虚线焦点框。
编辑器复用节点字体、正文内边距及最大文本宽度；短文字不再被额外的最小编辑宽度撑开，
长文字自动换行，并实时调整节点、标签及父子连接线。图片保留原位置，Markdown 节点编辑原始正文。
`Shift+Enter` 插入换行，`Enter`、`Tab` 或失焦提交，`Escape` 取消并恢复原内容与几何；
输入法预编辑参与尺寸计算，候选未结束时确认和取消键仍交给输入法。
草稿只覆盖画面，保留正式测量缓存、文档及历史；整次提交只生成一条引擎修改。
内置布局在独立持久化几何快照上局部试算，大图继续使用视口虚拟化；自定义布局仍经过注入注册表。

画布顶部提供固定路径栏，每个文件标签内可在主导图与多级子导图之间导航。
路径栏仅显示主导图到当前子导图的页面根节点，省略普通祖先节点；无选择、单选
和多选均保持同一页面链，多选另显示选中数量。页面项及“…”菜单均在文字左侧显示类型图标：
主导图使用主页、子导图使用树形分支、详情页使用圆形信息图标；长标题省略时预留图标宽度。
同名页面按标识区分，点击后定位对应页根；悬停提示和复制功能均使用完整页面路径。
引擎 `node_path(node_id)` 仍返回完整节点祖先路径，页面筛选仅发生在画布导航层。
`current_page_id` 返回当前页面标识，`None` 表示主导图；`create_submap()` 创建后
直接进入，`enter_submap(node_id)` 进入已有子图，`navigate_to(page_id, node_id)`
按路径切页定位，`return_to_parent_page()` 恢复上一级视图。`page_changed` 仅通知
页面变化，不属于引擎修改事件，不触发自动保存。`document_view` 始终只包含当前页，
`engine.document` 始终包含完整文件；图形导出读取当前页的正式快照。

宿主可用 `capture_page_view_state() -> dict[str, object]` 获取当前页的独立、可序列化
快照，字段为 `page_id`（主导图为 `None`）、`zoom`、场景中心 `center: [x, y]`、
`selection: [节点标识, ...]` 及导航临时范围 `focus_id`。不包含其他页缓存、Qt对象、
文档内容或输入草稿，查询不提交输入。隐藏标签和待初始化视图使用目标逻辑位置。
访问过独立想法时追加可选 `inspiration` 字段，保存当前根、最近根及逐想法独立
视口，不再写模式字段；普通附属页仍只持久化当前页。旧总览记录忽略总览视口，
恢复最近有效想法，否则首项或空态；旧记录中的有效单树视口仍保留，失效根记录跳过。
文件重新加载后、开始编辑前调用 `restore_page_view_state(state: Mapping[str, object]) -> None`，
恢复页面、倍率、位置及选择；只读同样可用，不改写折叠、历史或修改标记。
原页面不存在时回到主导图默认视图，几何字段无效时在有效目标页使用100%和根中心；
有限正倍率约束为10%～400%，中心沿用现有画布边界。选择只保留当前页可见节点，
显式空选择保持为空，非空选择全部失效时选中页根，不自动展开文档分支。
非映射参数、已释放画布、正文编辑或导航候选检查失败抛出中文 `MindMapError`；
恢复不提交面板草稿，不持有传入字典。两个接口均只在GUI线程、画布存活时调用。
组件不自行写配置，宿主拥有返回快照；实际定位等待显示与布局，文档替换或释放取消请求。

子导图路径栏右端显示收藏星标，主导图及详情页隐藏；节点右键的 `favorite_submap`
动作切换所选入口拥有的子导图收藏，目标与当前页星标独立。只读及正文编辑期间
禁用修改，输入法候选检查失败后星标恢复正式状态，不显示未提交的收藏结果。
`set_submap_favorite(page_id, favorite)` 检查目标、只读及候选状态，提交有效面板输入后
交给引擎修改；`toggle_submap_favorite(node_id=None)` 针对入口节点切换，省略节点时
使用当前节点。两者返回 None，失败抛出中文 `MindMapError`，宿主宜通过 `call()`
统一报告错误。收藏不切换页面或重置视图；撤销重做沿用操作所属页导航规则。

`create_detail_page()` 为当前节点创建单层详情并进入，`enter_detail_page(node_id)` 查看已有详情，
`delete_detail_page()` 确认后删除详情、保留原节点及其子导图。`current_page_kind` 返回当前页面
类别，详情路径末项显示“节点名称 · 详情”；通用导航、视图缓存、侧栏和只读浏览均复用页面能力。
详情信息圆圈与子导图树形分支图标常驻节点内部右侧，按详情、子导图排列，与外侧折叠按钮分开命中。
每个入口命中区域为 32×32、图形为 16×16，按钮间隔 2，正文到入口间隔 8，右侧留白 14，
单位均为 Qt 逻辑像素。测量在原内容宽度上增加按钮区，不压缩文字、图片和标签；无附页不留空白。
节点内容区上下各留 8；有入口的节点至少高 36，内容垂直居中。
原地编辑和输入法候选预览使用同一套尺寸规则。
悬停仅高亮当前入口，编辑与拖动期间不能切页，只读仍可导航；PNG、SVG、PDF 和拖动影像保留页面图标。
详情页内隐藏两类创建入口，核心同时拒绝直接调用。含附属页面的粘贴先显示省略范围，确认后
仅复制普通内容，取消不修改目标；删除含页面的分支同样先提示范围。两类页面共用全文件历史。

页面切换前通过 `edits_flush_requested` 提交有效草稿。外部面板可调用
`register_navigation_guard(callback)` 注册候选输入检查，回调返回 `False` 时保持原页；
返回的函数用于取消注册，`MindMapPanels` 已自动接入此能力。导航缓存不修改节点内容、
折叠状态或撤销历史，关闭画布后释放。页面按钮的命中与导航属于交互层，图形及占用尺寸由渲染包统一提供。

手动分支聚焦接口 `focus_node()` 及 `focus`、`unfocus` 动作已移除，右键菜单与宿主视图菜单
不再提供对应入口。`Ctrl+F` 没有默认画布绑定；`Escape` 只取消编辑、拖动或关闭菜单，空闲时
不改变视图。`navigate_to()` 定位折叠节点时仍可临时显示目标，返回页面时恢复该导航状态；
此机制不改写折叠字段、不进入撤销历史，也不提供独立聚焦入口。引擎布局接口保持兼容。

有子节点的主题在分支伸出方向显示外侧折叠按钮：展开时仅在悬停或选中时显示圆形“−”，
收起时始终显示直接子节点数量，不计入更深层后代；多位数字按实际宽度扩展为圆角徽标。
向右、向左、向下布局分别放在右侧、左侧、下方；双向布局跟随各分支方向，根节点固定在右侧。
按钮采用节点边框颜色和画布底色，随画布正常缩放。正文、节点到分叉点的短连线和分叉点附近均可唤出按钮，
即使按钮隐藏，感应区域也继续生效；连线两侧及按钮周围保留约 10 个视口像素，缩小导图后仍容易触发。
进入感应区域立即显示，移出后延迟 200 毫秒隐藏，再次进入取消隐藏；节点选中时和收起后的数字始终显示。
正文与按钮间的小间隙保持悬停，叶子不显示按钮；悬停连线只唤出按钮，点击圆形按钮才切换折叠。
点击只切换目标主题，保留后代自己的折叠状态和现有选择，支持一次撤销／重做及宿主自动保存。
只读模式和原地文字编辑期间不执行按钮操作。按钮不占用正文宽度或拖动区域，不进入图形导出及拖动影像；
添加子节点继续使用原有快捷键和菜单。
可在仓库根目录执行 `uv run --locked --all-packages python scripts/verify_fold_controls.py`，
在 `.artifacts/fold-controls` 下生成四方向、明暗主题的完整截图、按钮对照图及中文验收报告。

普通引擎提交通过隔离差量更新画布和大纲的读模型，不重新取得完整文档快照。
内置树布局以持久化摘要增量更新几何和连接线，超过 1000 个可见节点时仅维护视口及预取区图元。
选择、编辑和鼠标捕获节点固定保留；屏外选择、滚动、键盘导航及完整图形导出保持可用。
小图保留原有图元和动画，超过 500 个可见节点跳过重排动画。
导航临时显示、自定义布局及被覆写的内置算法保留完整布局和试算，扩展契约不变。
大图拖动仅查询局部候选，内置布局松手采用只回滚的增量预检；成功后执行一次正式操作。
面板复用分支样式摘要，大纲仅同步变化行和直接父级。

构造函数接受 `layout_registry` 和 `format_registry`，省略时分别创建独立默认实例。
画布与图形导出使用同一个布局注册表，剪贴板使用注入的 JSON、Markdown 和纯文本实现。
自定义格式注册表需保留这三个标识才能使用完整剪贴板能力。
Ctrl+V 和右键“粘贴”自动识别文本大纲；首个非空行符合 Markdown 标题或列表语法时
使用 Markdown，其他文本按一行一个节点、Tab 或每级 2／4 空格解析，支持多个并列根。
纯文本通过注入的 `text` 导入器读取并传入 `options={"as_fragment": True}`；自定义实现
需返回带隐藏合成根的 `MindMapDocument`，其 `root.children` 包含全部顶层节点。
解析器忽略 BOM、空行和整段共同缩进，保留正文内部空白；Tab 与空格混用仅接受可唯一
确定树形的内容，缩进错误、缺失父节点、跳级或歧义均报告原文行号，已确定格式不降级重试。
解析成功后每次均显示与亿图共用的配置弹窗，标题按来源显示“粘贴缩进大纲”或“粘贴 Markdown 大纲”，
单行文本也适用。单根内容允许追加或替换，替换时独立选择根节点及原有后代的处理方式；
多根只允许追加，不覆盖单根偏好。追加选中新顶层节点，替换选中原目标，整个操作可以一次
撤销／重做；保留的原有子节点排在新后代之前。无内容变化不创建历史，但可记忆成功确认的选择。
取消、失败或弹窗期间文档、页面、目标改变时不提交粘贴，也不改写共享偏好。灵感区无选择时
直接按整组游离树创建和落位，不弹出配置或更新偏好。
主导图、子导图、详情页共用这一入口，正文编辑及侧栏输入控件仍直接粘贴文本。
图片可直接通过 Ctrl+V 或节点右键“粘贴”创建纯图片子节点，支持截图、复制的图像、Qt 位图及独立编码图片 MIME。
编码图片保留原始字节，位图无损转换为 PNG 并保留透明度；每张图片沿用四千万像素上限。
使用当前节点作为父节点，多选时按树的先序顺序取第一个；无选择时使用导航临时节点，再回退到当前页根。
新节点追加到普通子节点末尾，展开父节点并选中新节点，保留父节点文字、图片和后代；保持当前页、缩放及视口位置。
默认以原图像素宽高作为逻辑尺寸，100% 画布倍率下不按 DPI/DPR 自动缩小，纯图片不受旧图文节点的最大文本宽度和图片限高影响。
新节点只显示图片，不绘制正文、标签等附加标记、背景和常驻边框；大纲及属性面板显示“图片”。旧图文节点不自动转换，显示及附件接口保持原样。
画布中的纯图片默认带低透明度的轻投影，未选中时悬停显示一个屏幕逻辑像素宽的细轮廓；选中后沿用蓝色轮廓及八个缩放手柄。
投影依照实际画布明暗调整对比度，仅绘制在图片外缘，不为透明区域添加底色，不修改原始图片字节或像素。
辅助效果只由交互图元及尺寸预览绘制，不计入节点测量、布局、命中区域、文档或历史，PNG／SVG／PDF 导出继续使用无投影、无悬停轮廓的正式图片。

主导图、子导图和详情页均可使用，图片资源随同一份原生文件保存，并参与自动保存、另存及资源去重。

## 文件生命周期

`MindMapFileController(canvas, panels, dialog_parent=None, *, writer=...)`
提供宿主无关的文件生命周期，不读写本机偏好，也不拥有画布。
`path` 表示当前保存位置，`is_dirty` 只反映引擎修改状态；有损文件导入及其待保存状态已删除。
`new_document()`、`open_path()`、`save()` 返回是否完成操作，
`confirm_replace()` 统一处理保存确认；主文档只使用 `.mindmap` 原生格式。
`open_path(path)` 仅接收 `.mindmap`，不再接受 `format_id` 参数；扩展名比较忽略大小写，始终使用原生容器解码。
`validate_open_path(path)` 在读取文件、分配会话和提交输入前校验扩展名；不匹配时抛出 `MindMapError`。
`open_dialog()` 只显示 `思维导图 (*.mindmap)`，取消或校验失败不改变当前文档；JSON、大纲及扩展格式不能用于文件打开。
保存、图形导出和确认替换前，控制器会提交有效属性输入与原地文字。
`save(save_as=False)` 的保存对话框固定显示 `思维导图 (*.mindmap)`，写入器始终接收 `format_id="mindmap"`，不再解析对话框格式名称或记录其他路径格式。
`validate_save_path(path)` 返回校验后的路径：没有扩展名时补齐 `.mindmap`，原生扩展名忽略大小写；其他后缀抛出 `MindMapError`，不静默改名或修改文件。
`save_committed()` 仅将已提交快照按当前路径原子保存为原生导图，返回是否成功；不弹出对话框、不提交侧栏草稿、不结束原地编辑。
该接口用于宿主自动保存，无绑定路径时报告失败；与普通保存共用路径校验和可注入写入器，成功才更新路径及保存标记。
即使快照未修改，也需验证绑定路径和原生编解码器，避免保存全部或关闭错误放行；原生编解码器不可完整读写时报告失败，不回退其他格式。
保存事件只更新状态，不触发画布的文档替换通知，不取消菜单、连接线预览或输入法，也不清空撤销历史。
`wait_for_pending_write` 可设置宿主写入屏障，默认不设置；文件替换、路径变化及显式写入前调用。
桌面工作台以该屏障等待在途后台保存，避免旧任务覆盖新版本；后台保存策略由宿主管理。
多导图宿主应为每份会话分别创建画布、面板组合和文件控制器，自行管理活动会话、文件归属、计时器及关闭策略。
文件解析和画布验证成功后才询问是否替换；写入成功后才更新路径与保存标记。
`export_dialog(format_id="svg")` 接受 `png`、`svg`、`pdf`，打开所选格式的保存对话框及折叠范围选择，默认使用 SVG。
默认文件名和唯一文件筛选对应所选格式；省略扩展名时自动补齐，其他扩展名或无效格式抛出 `MindMapError`。
取消文件选择时不询问导出范围，成功导出不更新保存位置，也不清除未保存标记。
文档导出专用的 `export_document_dialog()`、`export_path()` 已删除，不保留兼容接口。
`format_filters()` 仅接受 `open`、`save`，两者均固定返回 `思维导图 (*.mindmap)`；其他值抛出 `MindMapError`。
动态保存格式列表和筛选解析已删除，额外格式注册不能扩大文件操作范围；底层通用文件与内存编解码接口、原子写入继续保留。
JSON、Markdown 和文本仍服务剪贴板，不再作为文件控制器的保存目标；PNG、SVG、PDF 图形导出保持独立。
`open_path()` 的异常交给宿主处理；
`save()` 写入失败返回 False，并通过 `error_occurred(str)` 报告。
`state_changed` 通知文件状态变化，`message(str)` 提供导出结果提示。


`require_native_save_format()` 返回可完整读写的原生格式注册项；缺失或单向编码器抛出中文 `MindMapError`。
该检查不提交输入、不读写文件，也不改变路径或修改标记，可在后台保存预检时调用。
文件控制器仅要求 `PendingEdits.flush_pending_edits()`，无侧栏宿主可提供空实现。

界面色板使用 `set_ui_colors(UiColors | None)`，传入 None 恢复文档主题派生色板。
永久释放组件时调用 `dispose()`；暂时隐藏或切换标签不释放组件。
